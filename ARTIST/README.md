# ARTIST

게임 그림 원본은 이 폴더에서 엽니다. Aseprite로 저장하면 열린 Unity가 변경분을 기존 게임 에셋 경로에 적용합니다. Unity를 다시 열 때도 저장된 변경을 찾아 반영합니다.

## 작업 위치

| 폴더 | 작업 대상 |
| --- | --- |
| PALETTE | 게임 기준 팔레트 `necrohanderPalette.aseprite`. 효과·파티클·안개는 이 16열 × 9행 견본을 사용합니다. |
| PLAYER | 플레이어 본체, 손, 무기 |
| ENEMY / SUMMON / NPC | 몬스터, 보스, 소환수, 마을 캐릭터 |
| UI | 타이틀, 메뉴, HUD, 대화, 아이콘 |
| UI/Vector | 창·버튼·게이지·타이틀 등 크기를 바꾸어 그리는 UI의 SVG 원본 |
| EFFECT | 공격, 대시, 이동, 조명 이미지 |
| WORLD | 타일, 월드 오브젝트, 포탈, 함정 |
| [WORLD/Wildlife](WORLD/Wildlife/README.md) | 방울새의 대기·먹이 쪼기·경계·이륙·비행 태그와 편집 기준 |
| THIRD_PARTY | 기존 게임 프로젝트에 포함된 외부 아트 |
| LEGACY | 이전 그림과 배리언트 |

`*.from-png.aseprite`는 같은 이름의 Aseprite 원본과 별개로 연결된 PNG에서 만든 파일입니다. PNG를 변환한 원본에는 합성된 픽셀과 투명도가 들어 있습니다. 기존 Aseprite 원본은 레이어, 태그, 프레임을 포함합니다.

## 저장과 확인

나무에서 떨어지는 잎은 `EFFECT/AnimateParticle001.aseprite`에서 편집합니다. 128×128 캔버스의 중앙을 기준으로 그리며, 기본 애니메이션은 100ms씩 3프레임입니다. 태그 없이 저장하면 Unity가 전체 타임라인을 반복 재생합니다. 프레임을 추가하거나 시간을 바꿔도 같은 원본을 사용합니다. 떨어지는 경로와 간격은 나무 프리팹의 `TreeLeafFall`이 제어합니다.

1. `Tools > Sunyunie Panel > 아트`에서 폴더를 열고 편집할 파일을 고릅니다.
2. Aseprite에서 기존 캔버스와 프레임 구조를 기준으로 작업하고 저장합니다.
3. Unity 패널에 표시되는 마지막 성공 또는 오류를 확인합니다. 필요하면 **모든 원본의 변경 확인**을 누릅니다. PNG 출력이 있는 파일은 Aseprite가 필요합니다. Steam 기본 설치를 찾거나 패널에서 실행 파일을 지정할 수 있습니다.
4. 커밋에는 `ARTIST` 원본과 동기화된 Unity 에셋을 함께 넣습니다. 아티스트 외 팀원은 커밋된 출력으로 바로 열 수 있습니다.

마을의 `NPC/West_Saint.aseprite`는 11프레임입니다. 대기 루프는 첫 프레임을 0.10초 보여준 뒤 나머지 프레임을 재생합니다. 한 프레임만 수정하면 그 순간에 보이며, 계속 보일 의상이나 색은 해당하는 각 프레임에 그립니다. 기존 64×64 캔버스 안에서 실루엣을 넓혀도 Unity가 프레임을 다시 패킹해 반영합니다.

### 도트 아이콘 편집

캐릭터 정보(C)·아이템 주머니(V)·지도(Tab) 아이콘은 `UI/UI_Icon.aseprite`, 지도·나무 그림은 `UI/UI_Icons.aseprite`, 튜토리얼의 키캡과 마우스는 `UI/Tutorial/Tutorial.aseprite`에서 편집합니다. 미니맵 표식은 `WORLD/Icon_map_32px.aseprite`, 아이템 그림은 `WORLD/OBJECTS/Item.aseprite`에 있습니다. 기존 셀에 그린 뒤 저장하면 같은 그림을 쓰는 UI에도 반영됩니다.

### 벡터 UI 편집

`UI/Vector`에서 SVG를 엽니다. 같은 폴더의 `manifest.json`에서 원래 스프라이트의 경로와 이름을 확인할 수 있습니다. 캔버스 크기와 피벗 기준을 보존하고, 투명 영역·실루엣·강조색을 한두 가지 단색 면으로 만듭니다. 선, 글자, 필터를 사용한 경우 저장 전에 색이 채워진 패스로 변환합니다. 프레임을 고칠 때는 기존 원본의 9분할 모서리 안에 장식을 둡니다.

새 UI 오브젝트에는 `Vector Image`를 추가하고 매니페스트에 연결된 스프라이트를 지정합니다. 크기와 슬라이스는 Unity 스프라이트에서, 경로와 색은 SVG에서 읽습니다.

편집용 Python에는 프로젝트 루트에서 아래 패키지를 한 번 설치합니다. 설치와 무관하게 커밋된 메시로 게임을 실행할 수 있습니다.

```powershell
python -m pip install --target Library/ArtistSync/VectorPython shapely==2.1.2 svgelements==1.9.6
```

SVG를 저장하면 Unity의 `Tools > Sunyunie Panel > 아트`가 메시에 반영합니다. 에디터가 닫혀 있으면 다음에 열 때 변경을 확인합니다. 패널의 **벡터 UI 다시 빌드**로 바로 갱신할 수 있으며, 커밋에는 수정한 SVG와 `Assets/Resources/UI/VectorUiCatalog.asset`을 함께 넣습니다.

## 참조와 임포트

`manifest.json`은 원본별 Unity 경로와 원래 캔버스 규격을 기록합니다. 원본이 있던 경로의 Unity GUID, 슬라이스, 피벗, PPU, 타격 애니메이션 이벤트를 검사합니다. 참조가 바뀌는 편집은 동기화를 중단하며 Unity 출력에는 마지막 정상 버전이 남습니다. 캔버스 재설계, 태그 편집, 새 리소스 등록 시에는 Unity 쪽 임포트와 맵핑을 같이 검토합니다.

게임 스프라이트의 임포트 기준은 Point, 밉맵 비활성화, 무손실 임포트와 원본 해상도입니다. PPU, 9슬라이스, 콜라이더 관련 임포트 설정은 해당 에셋의 기존 값으로 관리합니다. 조명, 마스크, 인라인 글리프처럼 역할이 다른 리소스는 종류에 맞는 임포트 경로를 사용합니다.

외부 원본은 기존 Unity 에셋과 일치하도록 보관했습니다. 팀 밖으로 공유할 때는 원래 구매·배포 조건을 확인합니다. Aseprite 프로젝트와 Unity의 출력 포맷을 새로 생성해도 라이선스 조건은 같습니다.
