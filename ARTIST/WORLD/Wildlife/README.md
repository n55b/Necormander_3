# 방울새 · Dusk Finch

원본은 [DuskFinch.aseprite](DuskFinch.aseprite) 하나다. 캔버스는 24×24픽셀, 게임 밀도는 32 PPU다. 오른쪽을 보는 자세로 그리고 발 접점은 왼쪽 위 기준 (12, 20)에 둔다. 게임에서 이동 방향에 따라 좌우를 뒤집는다.

| Aseprite 태그 | 기본 프레임 | 게임에서 보이는 동작 |
| --- | --- | --- |
| Idle | 1–3 | 바닥에서 쉬며 고개를 들고 눈을 깜빡인다. 개체마다 다른 박자에 시작한다. |
| Peck | 4–7 | 부리를 바닥까지 내렸다가 돌아온다. |
| Alert | 8–9 | 플레이어 쪽의 기척을 듣고 고개를 든다. 가까운 새부터 이륙을 준비한다. |
| Takeoff | 10–12 | 몸을 낮추고 날개를 올려 발을 뗀다. |
| Fly | 13–16 | 날갯짓을 반복하며 무리에서 조금씩 다른 방향으로 날아간다. |

발은 **Feet**, 몸통·얼굴·꼬리는 **Plumage**, 앞쪽 날개는 **Wings** 레이어에서 고친다. 프로젝트의 기준 팔레트를 사용한다. 그림 안에는 그림자를 그리지 않는다. 게임이 현재 자세와 바닥 위치로 그림자를 그린다.

다섯 태그의 영문 이름을 유지하면 각 태그 안에서 프레임 수와 시간을 바꿔도 된다. 위치 이동과 상승 높이는 게임이 맡으므로 비행 셀에서도 몸 전체를 화면 끝으로 이동시킬 필요가 없다. Aseprite에서 저장하면 Unity가 원본을 동기화하고 태그로 애니메이션 클립을 다시 만든다. 필수 태그나 그림이 없으면 직전 출력을 복원한다.

마을에 들어가 잠시 지켜본 뒤 새 쪽으로 걸어가면 다섯 동작을 확인할 수 있다. 마을을 더 돌아다니면 이전 자리에서 멀어진 뒤 화면 밖의 새로운 지점에 다음 무리가 자리 잡는다. 던전에서는 일부 시작·일반·보상 방에 무리가 나타난다.
