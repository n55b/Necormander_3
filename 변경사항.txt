2026-10-26 — 이동 애니메이션 곡선

코드로 일정하게 움직이던 연출을 Unity 인스펙터의 그래프로 조절할 수 있게 변경했다.
Aseprite의 프레임 애니메이션과 타격 이벤트는 그대로 유지한다.

플레이어 대시: 출발할 때 빠르게 치고 나가고, 끝으로 갈수록 부드럽게 감속한다. 전체 시간의 절반에 거리의 약 75%를 이동한다.
평타 전진: 타격 순간에 전진하는 힘을 집중하고 빠르게 감속한다. 전체 시간의 절반에 거리의 약 83%를 이동한다.
이번 곡선 조절에서 이동 거리와 지속시간 설정은 바꾸지 않았다. 앞선 곡선 연결 작업에서 평타 전진의 마지막 이동 틱이 취소되던 처리는 수정했다.

수정 위치: Assets/Prefabs/Player Melee.prefab → PlayerController → Dash Movement Curve / Attack Dash Movement Curve.
그래프의 가로축은 경과 시간, 세로축은 이동한 거리의 비율이다. 둘 다 0~1 기준이다.
소환수 위치 이동, 보스 이동, 엘리트 도약·추격 감속, 잔상 소멸도 그래프로 편집 가능하게 했다. 첫 설정 당시에는 기존 직선 값을 유지했다.

플레이하며 확인할 점: 대시 출발이 너무 급한지, 끝에서 끌리는 느낌이 있는지, 평타 전진이 타격감과 잘 맞는지.
이후 요청한 변경도 이 파일 아래에 날짜별로 추가한다.

2026-10-26 — 나머지 연출과 플레이어 조작감

출발은 짧게 가속하고, 키를 떼면 짧게 감속한다. 반대 방향 입력에는 더 빠르게 돌아선다.
감속 중에는 걷기 모션 속도도 함께 줄어들고, 실제로 멈춘 뒤 Idle로 전환한다.
대시가 끝날 때 이동키를 누르고 있으면 바로 걷기로 이어진다. 키를 뗐으면 그 자리에서 멈춘다.
이동 보간은 물리 틱에서 처리한다. 문 이동의 입력 차단은 즉시 정지를 유지한다.

조절 위치: Assets/Prefabs/Player Melee.prefab → PlayerController → 조작감 설정.
Movement Acceleration Time = 0.045 / Movement Stop Smooth Time = 0.065 / Movement Turn Time = 0.022.
이 값은 부드러움의 반응 시간이며, 정확히 그 시간이 지나면 동작이 끝난다는 뜻은 아니다. 작을수록 빠르게 반응한다.
최대 이동속도와 대시 거리·지속시간은 그대로다.

보스 찌르기는 초반에 빠르게 뻗은 뒤 감속한다. 보스와 엘리트의 도약은 착지 쪽으로 갈수록 빨라진다.
엘리트 추격 버스트는 초반에 속도를 줄이고 부드럽게 평상시 속도로 돌아온다. 잔상은 처음엔 선명하다가 끝에서 빠르게 사라진다.
소환수 위치 이동과 보스 휩쓸기 전진도 빠르게 출발하고 부드럽게 멈추는 곡선을 넣었다. 현재 이동 오프셋/거리가 0인 항목은 제자리를 유지한다.
이 곡선들은 각 보스/엘리트 AI 에셋, 소환수 에셋의 Movement Curve, 몬스터 프리팹의 DashAfterimage → Fade Curve에서 조절한다.
Aseprite 그림과 타격 이벤트, 공격 예고·착지 타이밍은 유지한다.

참고: Celeste 공개 이동 코드의 목표 속도 접근 방식, Dead Cells 개발자 Deepnight의 이동·마찰/게임 필 자료. 수치는 이 게임에 맞춰 별도로 조절했다.
https://github.com/NoelFB/Celeste/blob/master/Source/Player/Player.cs
https://deepnight.net/tutorial/a-simple-platformer-engine-part-1-basics/
https://deepnight.net/games/game-feel/

플레이하며 확인할 점: 좌우 반전이 답답하지 않은지, 키를 뗐을 때 너무 미끄럽지 않은지, 대시 후 걷기가 자연스러운지.

2026-10-26 — 스쿼시/스트레치, 디더링, 최종 소환수 타격 연출

스쿼시/스트레치: 플레이어의 평타 전진·대시·대시 종료·피격·가드 성공 때 그림이 약 5~12% 늘거나 눌렸다 돌아온다. 충돌체·카메라·UI는 변형하지 않는다.
Player Melee 프리팹 → VisualSquashStretch에서 동작별 Scale/Duration/Curve를 조절한다. Visual에는 그림 전용 Transform을 넣는다.
다른 오브젝트도 이 컴포넌트를 직접 붙여서 사용한다. UnityEvent에서 Play(string)에 Attack/Dash/Land/Hit/Guard 또는 직접 만든 이름을 넣으면 된다. Squash()/Stretch()/ResetVisual()도 바로 호출할 수 있다.

디더링: 사물 뒤로 가려진 플레이어의 실루엣, 화면 페이드 인/아웃, 돌진 몬스터의 잔상이 도트 무늬로 나타나고 사라진다.
기존 Fader와 로딩 완료 대기 순서는 유지한다. 완전히 가려져야 할 때는 구멍 없이 가려진다.
재질은 Assets/Material/Feedback에 있다. 화면은 ScreenFadeCanvas → FadeImage, 플레이어는 Body/Hand 아래 Silhouette, 잔상은 DashAfterimage → Fade Material에서 교체한다.
다른 SpriteRenderer에도 Dither Afterimage 재질을 지정하면 Fader 등이 바꾸는 알파를 디더링으로 표현할 수 있다. 원래 재질 고유의 조명/외곽선이 필요한 오브젝트는 재질 교체에 주의한다.

슬래시: 최종 전사 계열 용사(Champion)와 최종 무사 계열 장수(Warlord)의 평타·Space·대시 적중에 제공된 Slash_Effect를 연결했다.
원본은 32 PPU로 가져오고, 반복하지 않는 복제 클립으로 재생한다. 복제 클립에서 앞뒤 빈 구간만 제거해 적중 순간부터 보인다. 적중점에 슬래시 중심을 맞추고 짧은 발광·가는 선 파편 5개를 더했다. 피해량과 타격 시점은 그대로다.
Assets/Prefabs/Effect/Hit/Slash Impact.prefab에서 크기·색·파편 배치를 직접 수정할 수 있다. ImpactFeedback의 곡선으로 확대·발광·소멸을 조절한다.
다른 타격 이펙트도 완성 프리팹으로 만든 뒤 해당 MainMinionDataSO의 Hit Effect Prefab에 넣는다. 비우면 기존 히트박스 이펙트를 쓴다.

참고: Celeste 공개 코드의 그림만 변형하는 방식과 Dead Cells 아트 개발기의 효과 합성 방식. 제공한 스프라이트와 기본 선 도형을 사용했다.

2026-10-26 — 연출 강화 2차 (위 초기 수치보다 이 항목이 최신)

스쿼시/스트레치를 몬스터 공용 프리팹과 소환수 7종에도 연결했다. 몬스터는 공격 시작/타격과 실제 체력 피해에 반응한다.
일반 몬스터·소환수는 약 11~20%, 플레이어는 동작별 최대 27%까지 변형된다. 빠르게 눌리거나 늘어난 뒤 반대 방향으로 한 번 튕겨 돌아오는 곡선이다. 큰 엘리트·보스는 강도를 낮춰 무게감을 유지했다.
몬스터는 그림과 충돌체가 같은 루트라, 기존 PlayerOramaticLit 셰이더 그래프에 그림 정점만 변형하는 _FeedbackScale을 추가했다. 실제 위치·충돌체·이동 판정은 그대로다.
소환수는 현재 체력이 없는 공격 퍼펫이므로 등장·공격 판정창·타격 펄스·대시 연출에 연결된다. 체력이 있는 캐릭터의 피격 연결은 VisualSquashStretch의 Health Source가 담당한다.
조절: 각 캐릭터 프리팹의 VisualSquashStretch → Pulses. UnityEvent 호출 방식은 동일하다. 몬스터는 Deform Renderer, 플레이어·소환수는 Visual을 사용한다.

피격 섬광을 더 밝고 짧게 바꿨다. CharacterVisualFeedback의 Hit Flash Strength(0.9) / Duration(0.075초)로 조절한다.
플레이어 대시에 청록색 디더링 잔상을 추가했다. 기존 DashAfterimage를 재사용하며, 걷기나 평타 전진에서는 생성되지 않는다. Player Melee 프리팹의 DashAfterimage에서 간격·수명·색을 바꾼다.
가림 실루엣은 밝은 청록색과 더 큰 도트 무늬를 사용한다. 화면 전환은 대각선으로 디더링이 퍼지는 방식으로 강화했다. 완전 암전과 로딩 완료 대기는 유지한다.
조절: Assets/Material/Feedback의 Dither Screen Fade → Pixel Size / Wipe Spread, Player Dither Silhouette → Dither Pixel Size. 플레이어 실루엣의 색은 PlayerOcclusionSilhouette에서 바꾼다.

용사·장수 슬래시는 크게 벌어지는 도트 슬래시 + 0.07초 중심 섬광 + 방사형 파편 9개 + 확산 호 2개 + 시간차 디더링 잔광 2장으로 강화했다. 전체 수명은 0.36초다.
각 요소는 Slash Impact.prefab 안에 실제 오브젝트로 배치되어 있다. 필요 없으면 해당 참조를 비우거나 요소를 제거할 수 있다. ImpactFeedback에서 확대·발광·소멸 곡선과 잔광 간격을 조절한다.
추가 히트스톱이나 카메라 흔들기는 넣지 않았다. 기존 공격/가드 타이밍을 유지하면서 그림의 반동·잔상·타격 효과로 변화가 보이도록 했다.

참고: Celeste 공개 코드의 시각적 변형, Dead Cells 개발자 Deepnight의 게임 필 데모. 아트는 제공된 스프라이트와 기본 선 도형을 사용한다.

2026-10-26 — 기획자용 한글 인스펙터와 레거시 재점검

게임 스크립트와 SO에 공통 한글 인스펙터를 적용했다. 중첩 목록도 한글로 표시하며, 항목 검색과 원래 코드 이름 표시를 지원한다. 이름 위에 마우스를 올리면 단위·역할·조절 범위를 볼 수 있다. 기존 필드 이름, enum 값, 프리팹 연결과 저장값은 유지했다.

영문 구역 제목 117곳과 선택지 이름 185개도 한글로 표시한다. Unity/패키지 기본 컴포넌트와 Aseprite/Animator 호출 키는 원래 이름을 사용한다.
주요 곡선은 X/Y축의 의미를 설명했고, 기존 슬라이더·색상·곡선 편집기·UnityEvent는 유지했다. 씬 오브젝트의 플레이 중 수정은 종료 시 돌아간다. SO 에셋 수정은 남을 수 있으므로 원래 값을 기록한다.

연출과 공격에 박혀 있던 값 26개를 기존 담당 컴포넌트/SO에 추가했다.
- ImpactFeedback: 파편/파동의 수명 비율·크기·투명도, 순간 섬광의 시간·크기.
- TextFloating: 일반/치명타 숫자의 반동 시간·횟수·회전 각도·가로 흩어짐.
- CharacterVisualFeedback: 피격 색 변화 시간, 플레이어 피격 히트스톱과 화면 가장자리 색 변화 시간.
- VisualSquashStretch: 연타 시 이전 반동을 섞는 시간 비율.
- EnemyMagicianAIPatternSO: 장판 피해 판정 유지 시간.
- ArcherBossAIPatternSO: 포격 예고 시간, 반경, BaseHitBox 판정 유지 시간.
초기값은 기존 코드의 값과 같다. 숫자 연출의 punchDuration/CiriPunchDuration은 실제로 크기 값이라 그 역할에 맞게 표시했다.

미사용 필드 12개는 ‘사용 안 함’으로 표시했다. 옛 Git 작업 도구 2개와 현재 프리팹에 연결되지 않은 EnemyMagicianCircleAttack/궁수 호환 분기도 정리 후보로 확인했다. 이번에는 삭제하지 않았으며 현재 사용 중인 데이터/저장 호환 코드는 유지했다.

2026-10-26 — 상자·대시·이동 애니메이션 교체
Object/Chest.aseprite를 일반 보상 상자와 소환수 보상 상자에 연결했다. 평소에는 닫힌 그림으로 보이고, F로 열면 Chest_Open 모션을 끝까지 재생한 뒤 기존 보상을 지급한다. 새 그림자의 추가로 몸통 위치가 달라지지 않도록 피벗도 맞췄다.
Dash_Effect.aseprite는 위쪽 이동에 Up, 아래·수평 이동에 Down을 사용하고 좌우 방향에 맞춰 반전한다. 원본 16×16 캔버스 밖에도 작업용 그림이 남아 있어, 원본은 그대로 보존하고 Unity용 Sprite 사본에서 캔버스 안쪽만 사용한다.
