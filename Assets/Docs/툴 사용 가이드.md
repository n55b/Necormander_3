# Necromander 툴 사용 가이드

프로젝트 안에 있는 에디터 툴과 게임 속 디버그 기능을 한곳에 모았습니다.
메뉴는 모두 유니티 상단 **Tools** 메뉴 아래에 있습니다.

> **읽는 법**
> - **기획자용**: 수치·모양·소리를 직접 만지는 툴입니다. 대부분 플레이 중에 바꿔도 바로 보입니다.
> - **셋업/배선**: 프리팹이나 에셋을 고치는 툴입니다. 누르기 전에 Git에 커밋해 두면 되돌리기 쉽습니다.
> - **검사**: 이름에 `Verify` / `Check` / `검증` / `검사` 가 붙은 메뉴는 **씬·에셋·세이브를 저장하지 않는** 회귀 검사입니다. 결과는 콘솔이나 `Logs/`, `Temp/` 폴더의 리포트로 나옵니다. 안심하고 눌러도 됩니다.

## 1. 기획자용 툴

### 1-1. UI 스킨 · 연출 설정 — `Tools > UI 스킨`

인게임 UI(체력바, 쉴드, 가드, 스킬 칸, 미니맵, 아이템 주머니, 장착 정보, 툴팁)의 **모양**과 **움직임**을 파일 하나에서 조절합니다.
소환수 선택 · 보상 선택 · 증강 선택 화면은 이 툴이 건드리지 않습니다.

| 메뉴 | 하는 일 |
|---|---|
| **스킨 · 연출 설정 열기** | 설정 파일 `Assets/Resources/UI/UISkinSettings.asset` 을 선택합니다. 없으면 만들어 줍니다. |
| **인게임 UI 프리팹에 스킨 붙이기** | 위 UI 프리팹들에 스킨 부품과 연출을 붙입니다. 여러 번 눌러도 안전합니다(플레이 중에는 안 됨). |

**설정 파일에서 할 수 있는 것** (모든 칸에 마우스를 올리면 설명이 나옵니다)

- **① ~ ③ 모양**: 역할(큰 창, 안쪽 패널, 체력바 테두리, 미니맵 테두리, 아이템 칸 …)마다 `스프라이트`, `색`, `그리는 방식`, `테두리 굵기 배율` 을 정합니다. 한 번 바꾸면 같은 역할의 UI 가 전부 바뀝니다.
- **④ 공통**: 연출 전체 켜기/끄기, 일시정지 중에도 재생할지, '툭 튀는 모양 곡선'.
- **⑤ 창 열림**: 큰 창 / 작은 창(툴팁) 각각 시작 크기, 걸리는 시간, 시작 투명도, 시작 위치, 곡선, 지연.
- **⑥ 체력 · 가드 게이지**: 피해 잔상(색·머무는 시간·줄어드는 시간·곡선), 맞았을 때 번쩍임·툭 튀기, 회복·보호막 번쩍임, 위험 경고(시작 비율·깜빡임 주기·색·세기).
- **⑦ 스킬 아이콘**: 쿨타임 중 테두리 색, 준비 완료 순간의 번쩍임·튀어오르기.
- **⑧ 마우스 반응**: 아이템 칸·버튼에 마우스를 올렸을 때 / 눌렀을 때 크기.

설정 화면 위쪽 버튼: **모양을 UI_Panel 기본값으로**, **연출을 기본값으로**, **인게임 UI 프리팹에 스킨 다시 붙이기**.

> 💡 플레이하면서 값을 바꾸면 즉시 보이고, 값은 그대로 저장됩니다.
> 💡 특정 창만 열림 연출을 다르게 하려면 그 창의 **창 열림 연출** 컴포넌트에서 `연출 종류` 를 `직접 설정` 으로 바꾸세요.

**관련 컴포넌트** (`Add Component > UI 스킨`)

| 컴포넌트 | 설명 |
|---|---|
| 스킨 이미지 (UI_Panel) | 이 Image 를 스킨 설정의 한 '역할'로 칠합니다. `원래 색 유지` 를 켜면 그림만 바꾸고 색은 코드가 정한 대로 둡니다. |
| 창 열림 연출 | 켜질 때 크기·투명도·위치를 움직여 등장시킵니다. |
| 마우스 반응 | 마우스 올림/누름 크기 변화. |
| 게이지 연출 (체력 · 가드) | 피해 잔상, 번쩍임, 위험 경고. 바의 값을 읽기만 합니다. |
| 스킬 아이콘 연출 | 쿨타임 중 테두리 어둡게, 준비 완료 번쩍임. |
| 항상 맨 앞에 그리기 | 나중에 생기는 형제(미니맵 방 아이콘 등)보다 항상 위에 그립니다. |

### 1-2. 사운드 테스트 툴 — `Tools > 사운드 > 사운드 테스트 툴`

소리를 넣고 **바로 들어보는** 창입니다. 위쪽 탭이 두 개입니다.

- **[오브젝트 소리]**: 몬스터 · 소환수 · 캐릭터 · 사물의 소리 (아래 설명)
- **[UI 소리]**: 창 열림/닫힘, 버튼 · 아이템 칸, 상점 구매 성공/실패 소리 (→ 1-2-1)

**오브젝트 소리 — 기본 순서**

1. Project 창에서 프리팹(예: 몬스터 프리팹)을 클릭합니다. (`선택 따라가기` 가 켜져 있으면 자동으로 대상이 됩니다)
2. 사운드 세트가 없으면 **이 프리팹에 사운드 세트 붙이기** 를 누릅니다.
   - 씬 오브젝트를 골랐다면 **프리팹 원본에 붙이기(권장)** 를 누르면 같은 프리팹을 쓰는 모든 오브젝트에 들어갑니다.
3. **+ 소리 추가 ▼** 에서 `공격 / 피격 / 사망 / 회복 / 등장 / 스킬 / 발소리 / 직접 호출` 중 하나를 고릅니다.
4. 오디오 파일을 **"여기에 오디오 파일을 끌어다 놓으세요"** 칸에 끌어다 놓습니다. 여러 개 넣으면 매번 무작위로 하나가 나옵니다(같은 파일 연속 방지).
5. **▶ 테스트** 로 들어봅니다. 볼륨·음높이·무작위 선택이 실제 게임처럼 적용됩니다. 파일 옆 ▶ 는 그 파일만 들려줍니다.

**화면 구성**

| 위치 | 기능 |
|---|---|
| 위 막대 | 대상 고르기, 선택 따라가기, **미리듣기 볼륨**(툴 전용, 게임 값 안 바뀜), **단순 미리듣기**(▶ 를 눌러도 소리가 안 나면 켜 보세요), **■ 정지** |
| 왼쪽 | 소리 목록. 이름, **언제 재생**, 소리 파일들, 볼륨, 음높이 범위(최소~최대 무작위), 최소 재생 간격, 지연 |
| 오른쪽 | **오디오 파일 찾기**: 이름으로 검색 → ▶ 로 듣기 → 왼쪽 소리의 체크칸을 켜고 **[+]** 로 추가. 목록에서 왼쪽으로 끌어다 놓아도 됩니다. 더블클릭하면 Project 창에서 위치를 보여줍니다. |
| 아래 | **재생 기록**: 플레이 중 실제로 난 소리(시각 · 누가 · 어떤 소리 · 어떤 파일)와 **열리고 닫힌 창 이름**. "왜 소리가 안 나지?"를 확인할 때 씁니다. |

**"언제 재생" 종류**

| 선택지 | 연결 방식 |
|---|---|
| 나타날 때 | 오브젝트가 켜질 때 (소환, 스폰) |
| 공격이 맞는 순간 | 애니메이션 이벤트 `OnHitEvent` (몬스터 공격 클립에 이미 들어 있는 이벤트) |
| 공격 동작 끝 | 애니메이션 이벤트 `OnAttackEndEvent` |
| 맞았을 때 / 회복했을 때 / 죽을 때 | 같은 오브젝트(또는 자식)의 체력(CharacterHealth)에 자동 연결 |
| 직접 호출 | 애니메이션 이벤트 함수 이름 `PlaySound`, 문자열 인자에 **소리 이름** (예: `발소리`). 코드에서는 `GetComponent<EntitySoundSet>().PlaySound("발소리")` |

> 💡 Animator 가 자식 오브젝트에 있어도 괜찮습니다. 실행 중에 중계 컴포넌트가 자동으로 붙어 이벤트를 받아옵니다.
> 💡 **최소 재생 간격**: 몬스터 여러 마리가 한꺼번에 맞을 때 같은 소리가 겹쳐 터지는 것을 막습니다.
> 💡 플레이 중이고 대상이 씬 오브젝트면 **게임▶** 버튼이 생깁니다. 옵션의 효과음 볼륨·믹서까지 반영해서 게임 안에서 재생합니다.
> 💡 사운드 세트 인스펙터의 **사운드 테스트 툴에서 열기** 버튼으로도 열 수 있습니다.

플레이어의 공격·구르기·가드·피격 소리는 기존처럼 `PlayerAttackSoundData`(Create > Audio > PlayerAttackSoundData) 에서 관리합니다.

#### 1-2-1. UI 소리 — 사운드 테스트 툴 [UI 소리] 탭

설정 파일: `Assets/Resources/UI/UISoundSettings.asset` (메뉴 `Tools > 사운드 > UI 소리 설정 열기` 로도 선택됨)
처음 만들 때 GameManager 프리팹의 예전 UISoundController 에 들어 있던 기본 열림/닫힘 소리를 자동으로 옮겨 왔습니다.

| 구역 | 내용 |
|---|---|
| **UI 소리 켜기** | 끄면 아래 모든 UI 소리가 꺼집니다. |
| **① 창 열림 · 닫힘** | `기본 열림 / 기본 닫힘 소리` + **창마다 다른 열릴 때 / 닫힐 때 소리**. 창의 소리가 비어 있으면 기본 소리가 납니다. |
| **② 버튼 · 아이템 칸** | 버튼 마우스 올림 / 클릭, 아이템 칸 마우스 올림 / 클릭, 탭 클릭, 마우스 올림 소리 최소 간격 |
| **③ 상점** | **구매 성공**, **구매 실패**(골드 부족 · 살 수 없는 상품 · 강화 상점 골드 부족 포함) |

모든 소리 칸은 오브젝트 소리와 똑같이 **끌어다 놓기 / ▶ 테스트 / 체크 후 [+]** 로 다룹니다. 여러 파일을 넣으면 무작위, 볼륨과 음높이 범위도 칸마다 따로 있습니다.

**창 이름 목록** (코드가 보내는 이름 — 목록의 `[ ]` 안에 보임)

| 창 이름 | 화면 |
|---|---|
| Reward | 보상 선택 |
| HandSlot | 소환수 습득 · 교체 |
| Augment | 증강 선택 |
| Map | 전체 지도 (M) |
| Shop | 상점 |
| Dialogue | 대화 |
| Pouch | 아이템 주머니 (V) |
| PlayerInfo | 장착 정보 (C) |
| PlayerInfoDetails | 장착 정보 · 상세 펼치기 |
| Option | 옵션 (ESC) |
| GameOver / GameClear | 게임 오버 / 클리어 (열림만) |

> 💡 새 창이 생기면 **+ 창 추가 ▼** 에서 고르거나 이름을 직접 입력하세요. 플레이 중 창을 열고 닫으면 재생 기록에 실제 이름이 찍히고, 목록에 없는 이름은 `(목록에 없음 → 기본 소리)` 로 표시되며 **+ 창 추가** 메뉴에도 나타납니다.
> 💡 새 창을 코드로 만들 때는 열 때 `UIEventBus.NotifyOpen("이름")`, 닫을 때 `UIEventBus.NotifyClose("이름")` 를 부르면 됩니다.

**버튼 소리 붙이기** — `Tools > 사운드 > UI 버튼에 소리 붙이기` (또는 [UI 소리] 탭 위쪽 버튼)

- 인게임 UI 프리팹의 버튼에 **UI 버튼 소리** 컴포넌트(`Add Component > 사운드 > UI 버튼 소리`)를 붙입니다. 이미 붙어 있는 버튼은 건드리지 않으니 여러 번 눌러도 안전합니다.
- 아이템 주머니 칸은 `아이템 칸`, 정렬 버튼은 `탭 버튼`, 나머지는 `일반 버튼` 으로 자동 분류됩니다.
- 상점 구매 버튼은 성공/실패 소리가 따로 나므로 `클릭 소리` 가 꺼진 채로 붙습니다.
- 컴포넌트에서 종류, 마우스 올림 / 클릭 소리 켜기, **이 버튼 전용 소리**(비우면 공용 소리)를 고칠 수 있습니다. 눌릴 수 없는(비활성) 버튼은 소리를 내지 않습니다.
- 씬에만 있는 UI(옵션 창 등)의 버튼은 직접 컴포넌트를 붙이면 됩니다.

> ⚠️ 상점에서 골드가 모자라도 구매 버튼은 이제 **눌립니다**(글자는 "골드 부족" 그대로). 눌렀을 때 실패 연출과 **구매 실패** 소리가 나도록 하기 위해서입니다.
> 💡 연출(피드백)의 `Purchase` 에 이미 소리가 들어 있다면 **구매 성공** 칸은 비워 두어 겹치지 않게 하세요.

### 1-3. 소환수 공격 범위 표시 — `Tools > 디버그 > 소환수 공격 범위 표시` (Alt + Shift + H)

소환수 마무리 일격 · Space 스킬 · 대쉬 피해의 **범위 그림**을 켜고 끕니다. 판정·데미지는 바뀌지 않습니다.

- 체크 = 보임(디버그), 체크 해제 = 숨김(기본). 바꿀 때 Game/Scene 뷰에 알림이 뜹니다.
- 플레이 중에도 바로 바뀌고, 설정은 이 PC 에 기억됩니다.
- **에디터 전용**입니다. 빌드한 게임에서는 항상 숨김.
- 플레이어 본인 평타 범위는 `MeleeCombatController` 의 **평타 범위 표시 숨김** 옵션이 따로 관리합니다.

### 1-4. 연출(피드백) — `Tools > 연출`

| 메뉴 | 하는 일 |
|---|---|
| 기존 연출을 Catalog에 연결 (값 유지) | 기존 연출 설정은 원본에 둔 채, Catalog 에 분류·사용 여부·원본 연결만 저장합니다. |
| 프리팹 배선 확인 및 누락 연결 | 신규 연출 프리팹의 빠진 연결을 채웁니다. 기존 기획 수치는 덮어쓰지 않습니다. |
| 전체 연출 배선 검증 | 연출 배선 상태를 검사합니다. |

FeedbackCatalog 에셋 인스펙터에서 항목별 **조절** 버튼으로 값을 펼쳐 볼 수 있습니다.

컴포넌트를 붙이고 '반응 목록'에 "어떤 신호 → 얼마나 세게"를 적는 방식입니다. 자세한 사용법은 `Assets/Scripts/UI/Tool/Fader, Shaker 사용법.txt` 를 보세요.

| 컴포넌트 | 테스트 방법 |
|---|---|
| CameraShaker (카메라 리그에 1개) | 컴포넌트 우클릭 → **Test - Shake** |
| UIShaker (흔들 UI 부품마다) | 컴포넌트 우클릭 → **Test - Shake** |
| Fader (붙인 대상이 페이드) | 컴포넌트 우클릭 → **Test - FadeOutIn** |

### 1-6. 한글 인스펙터 — `Tools > 기획`

인스펙터 항목 이름을 한글로 보여주는 기능이 프로젝트 전체에 들어가 있습니다(저장 키는 그대로).

| 메뉴 | 하는 일 |

## 2. 게임 속 디버그 기능

| 기능 | 사용법 |
|---|---|
| DPS 미터 + 플레이어 스탯 | 플레이 중 **F5** = 함께 켜기/끄기, **F4** = DPS 기록만 초기화 |
| 상태이상 부여 | 씬에 `StatusDebugKeys` 가 있으면 숫자 **1~5** 로 씬의 모든 적에게 상태이상을 1회 겁니다(비폭은 10번 쌓여야 터짐). |
| 시작 층 / 엘리트 방 테스트 | `GameManager` 인스펙터의 `debugStartFloor`(시작 층), `debugEliteArena`, `debugForcedElite`(강제할 엘리트). 확인: `Tools > Map > Verify Debug Start Floor` |
| 상점 반복 강화 | `GameManager` 인스펙터의 디버그 옵션: 같은 상점에서 장비를 여러 번 강화. **배포 시 꺼둘 것** |
| 튜토리얼 강제 시작 | StartScene 의 `MainMenuManager` → **Debug Force Tutorial** |
| 마을 디버그 로드아웃 | 마을 NPC 창(F)에서 미니언·장비·우클릭·주머니 아이템을 골라 미리 조합을 세팅 (`VillageDebugLoadout`) |
| 소환수 공격 범위 | 1-3 참고 (Alt + Shift + H) |
| 데모 빌드 초기화 | `DEMO_BUILD` 로 만든 실행 파일은 실행할 때마다 진행 데이터를 초기화합니다. |
