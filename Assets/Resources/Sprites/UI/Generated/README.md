## UI_HpbarWhite.png (164 x 9)

**무엇**: `../UI.png` 의 `UI_Hpbar` 서브스프라이트(빨간 체력바, rect 50,505 164x9)를
형태 그대로 두고 **색만 무채색으로 바꾼 것**.

**왜**: UI `Image.color` 는 텍스처에 **곱셈**이라, 이미 빨간 스프라이트는 어떤 색을 곱해도
밝아지지 않는다(흰색을 곱하면 그대로 빨강). 색을 바꾸려면 무채색 원판이 필요하다.
이게 있으면 `Image.color` 하나로 흰색/파랑/무엇이든 낼 수 있다.

**어떻게**: 픽셀별 상대휘도(0.2126R + 0.7152G + 0.0722B)를 구해, 가장 밝은 픽셀이 255 가
되도록 정규화. 명암 관계(외곽선 < 음영 < 본체 < 하이라이트)는 비율 그대로 보존된다.

| 원본 (RGB) | 역할 | 결과 (무채색) |
|---|---|---|
| 228, 119, 119 | 하이라이트 | 255 |
| 203, 87, 94 | 본체 | 201 |
| 176, 62, 82 | 음영 | 157 |
| 152, 47, 78 | 외곽선 | 128 |

모서리 4px 투명은 그대로 유지.

**임포트 설정**: `../UI.png` 와 동일하게 맞춤 — Point 필터, PPU 32, FullRect 메시
(Filled 이미지에 필수), 압축 없음, 9-slice border (5, 0, 5, 0).

**용도**: 우클릭 가드의 보호막 게이지. 체력바 뒤에 같은 자리로 깔고
`fillAmount = (CurHP + TotalShield) / MaxHP` 로 돌리면, 앞의 빨간 체력바가 왼쪽을 덮어서
체력이 끝나는 지점부터 보호막 색이 이어져 보인다.

**재생성**: 원본 아트가 바뀌면 이 스크립트를 다시 돌리면 된다 (경로만 맞춰서).
