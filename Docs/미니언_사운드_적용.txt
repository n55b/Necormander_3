미니언 사운드 적용 및 조절 — 2026-10-30

현재 소환수 7종의 평타·스킬에 반영. 전사·무사·기사·용사·장수·Dash Doll은 휘두르기와 실제 적중을 분리했다. 얼음 마법사는 요청대로 전용 사운드를 주문음만 연결했다. 기존 상태이상 적용음은 별도로 유지한다.
Dash Doll의 실제 적중음은 사용자가 고른 Mixkit Body punch quick hit(2153)로 연결했다. 공통 Enemy_Hit_1까지 중복해서 섞지 않도록 미니언 평타·스킬에서는 공통 타격음을 제외한다. 플레이어 평타와 기존 소환수 대시 공격의 공통 소리는 유지한다.

휘두르기: 애니메이션 OnHitEvent의 실제 프레임. 공격 속도에 따라 그림과 함께 움직인다. 빗나가도 재생한다.
적중: CharacterHealth가 무적·회피를 통과하고 양수 피해를 확정한 시점. 보호막을 맞혀도 적중으로 취급한다. 0 피해·무적·MISS에서는 나지 않는다.
연속타·다중 대상의 볼륨 폭증 방지: 묶음별 0.08초, 같은 파일 공통 0.07초 간격. 너무 촘촘한 타격은 일부 적중음을 생략하며 피해 자체는 바꾸지 않는다.
휘두르기 피치 0.96~1.04, 적중 0.96~1.03, 볼륨 ±7% 무작위. 같은 파일 연속 선택 방지. 무작위 지연 없음.
Dash 적중음의 스킬 피치만 0.94~1.00으로 조금 낮췄다. 얼음 평타 피치 0.98~1.03, 스킬 0.97~1.03. 들리는 거리 22. 우선순위 휘두르기 128 / 적중 112.
기존 SoundManager의 16개 소스 풀을 사용한다. 새 AudioSource를 타격마다 만들지 않는다.

[플레이 확인]
1. 각 미니언으로 빈 곳을 향해 평타: 휘두르기만 들리는지 확인.
2. 적에게 평타: 휘두르기+실제 적중이 겹쳐도 크게 튀지 않는지 확인.
3. 스킬은 대상이 필요하므로 적에게 사용한 뒤 범위를 벗어나게 하거나 무적 허수아비로 비교.
4. 용사·장수 연속타/다수의 적 적중 시 소리가 과밀하지 않은지 확인.
5. 얼음 마법사는 ice / Freeze Spell 구분, Dash Doll은 빗나가면 바람 소리만, 적중하면 짧은 thud가 함께 나는지 확인.

추가 검증: DashDoll 프리팹의 평타·스킬 적중 참조 2개, 기존 휘두르기 묶음 2개 유지, PCM/미리 로딩/Normalize 꺼짐을 편집 모드에서 확인. 실제 청감 테스트는 사용자 확인 대기.
