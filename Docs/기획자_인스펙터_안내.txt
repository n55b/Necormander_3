기획자용 인스펙터 안내
2026-10-26

1. 사용하는 방법

프로젝트의 게임 컴포넌트나 SO를 선택하면 한글 인스펙터가 나온다.
맨 위의 ‘항목 검색’에 대시, 준비, 회복, 곡선 등을 입력한다.
접힌 목록 안의 설정도 검색한다. 원래 영문 필드 이름으로도 검색할 수 있다.
‘코드 이름’을 켜면 개발자에게 전달할 원래 이름을 함께 볼 수 있다.
항목 이름 위에 마우스를 올리면 설명, 단위, 범위와 코드 이름이 나온다.

필드의 저장 이름과 에셋 GUID, 프리팹 연결은 바꾸지 않았다.
기존 범위 슬라이더, 색상 선택기, 곡선 편집기, UnityEvent 연결을 사용한다.
목록 왼쪽 손잡이로 순서를 바꾸고 + / -로 항목을 추가/삭제한다. Ctrl+Z로 되돌릴 수 있다.
‘사용 안 함’으로 표시된 회색 항목은 현재 실행 코드가 읽지 않는 옛 필드다.

씬 오브젝트에서 플레이 중 조절한 값은 종료 시 되돌아간다. SO 에셋 수정은 남을 수 있으므로 원래 값을 기록한다.
마음에 드는 값을 적어 두었다가 종료 후 원본 프리팹이나 SO에 적용한다.
프리팹 인스턴스를 바꿀 때는 해당 인스턴스만 바꿀지 원본에 적용할지 구분한다.
시작할 때 읽어서 내부에 저장하는 설정은 실행 중 변경이 즉시 반영되지 않을 수 있다.

2. 먼저 찾아볼 설정

플레이어 이동/대시/평타 전진
Assets/Prefabs/Player Melee.prefab
- PlayerController: 출발 가속 시간, 정지 감속 시간, 방향 전환 시간, 전진 곡선.
- MeleeDodgeController: 대시 속도, 지속 시간, 충전 시간과 횟수.
- MeleeCombatController: 평타 전진 배율, 콤보 유지 시간, 공격 예고.
- PlayerParryController: 최대 게이지, 퍼펙트 판정 시간, 일반 회복량, 파괴 완충 시간.
일반 시간은 초, 배율 1은 원래 값이다. 이동 속도와 지속 시간을 같이 바꾸면 거리도 바뀐다.

몬스터/보스 공격
Assets/SOData/Enemy/Enemy AI Patterns
- 각 패턴 SO에서 준비 시간, 사거리, 후딜, 이동 곡선을 조절한다.
- Bone Master의 1/2페이즈 설정은 서로 다른 SO다.
- 휩쓸기 반각 90도는 전체 180도 반원이다.
- 휩쓸기 회전 속도 0은 무제한. 전진 거리 0은 제자리 공격이다.
- 집행 카운터 횟수는 ‘성공 횟수’가 아닌 ‘기회를 준 횟수’다.

소환수
Assets/SOData/Minion의 MainMinionDataSO
- 평타/스킬/대시 애니메이션 묶음의 단계, 위치 보정, 이동 곡선을 조절한다.
- Aseprite 태그, Animator 상태 이름, OnHitEvent 같은 호출 키는 실제 이름을 유지한다.
- 타격 이벤트가 있는 애니메이션은 이벤트 프레임이 판정 시점을 결정한다.

눌림·늘어남
각 캐릭터 프리팹의 VisualSquashStretch → 동작별 변형
- 최대 변형 배율: 1,1은 원래 모양, 1.2,0.8은 가로 20% 증가/세로 20% 압축.
- 곡선: X는 시간 진행률, Y는 변형량. 음수로 내려가면 반대 방향 반동.
- 플레이어/소환수는 그림 전용 오브젝트, 몬스터는 그림 렌더러를 사용한다.
- 충돌체가 있는 물리 루트를 그림 전용 오브젝트로 지정하지 않는다.
- 이전 반동 혼합 비율로 연타 때 기존 반동이 얼마나 오래 섞일지 조절한다. 기본 0.2 = 전체 동작의 앞 20%.

슬래시 타격 효과
Assets/Prefabs/Effect/Hit/Slash Impact.prefab → ImpactFeedback
- 기존 수명, 잔광 간격, 확대/발광/소멸 곡선.
- 추가: 선 파편 수명 비율/크기, 원형 파동 수명 비율/투명도/크기, 섬광 시간/크기.
- 크기 범위의 X는 시작 배율, Y는 끝 배율이다.
- 수명 비율 0.65는 전체 수명의 65% 지점에 해당 요소가 사라진다는 뜻이다.

피격 반응과 데미지 숫자
- CharacterVisualFeedback: 피격 섬광, 색 변화 시간, 플레이어 피격 히트스톱, 화면 가장자리 색 변화 시간.
- TextFloating: 숫자 흩어짐, 일반/치명타 확대·위치·회전 시간, 반동 횟수와 강도.
- 옛 punchDuration/CiriPunchDuration은 이름과 달리 ‘시간’이 아니라 ‘튀는 크기’였다. 인스펙터에 실제 역할로 표시했다.
- 이번에 꺼낸 모든 값의 초기값은 기존 코드의 숫자와 같다. 초기 게임 템포는 바뀌지 않는다.

EnemyMagicianAIPatternSO에는 예고 후 장판 판정이 유지되는 시간을 추가했다.
ArcherBossAIPatternSO에는 포격 예고 시간, 반경, BaseHitBox 판정 유지 시간을 추가했다.
기존 준비/주기 설정과 함께 조절한다. 기본값은 각각 이전 코드의 값과 같다.

3. 범위와 유지보수

게임 C# 컴포넌트/SO와 중첩 데이터에 공통 적용한다. 기존 CharacterStat/GrowthRegistry 전용 인스펙터도 같은 표시를 쓴다.
Unity/패키지 기본 컴포넌트, 셰이더/재질, Aseprite/Animator 호출 키까지 번역하거나 이름을 바꾸지는 않는다.
사용자 정의 선택지에는 InspectorName만 붙였다. enum 숫자와 코드 이름은 같다.

공통 표시 코드: Assets/Editor/DesignerInspector
정확한 의미가 필요한 항목은 DesignerInspectorLabels의 SpecificData에서 설명한다.
새 필드를 추가하면 Tools → 기획 → 한글 인스펙터 검증으로 실제 에셋의 번역 누락과 직렬화/Undo를 확인한다.
이 도구는 게임 에셋을 저장하지 않는다. 결과는 Logs/Designer-inspector-coverage.txt에 남는다.

검증 기록
- 코드의 직렬화 후보 1,341개를 조사했다(실행 중 상태/저장 데이터도 포함).
- 실제 프리팹/SO 3,022개 컴포넌트·데이터에서 고유 표시 필드 1,206개의 한글 표시를 검사했다.
- Undo, 다중 선택 편집, 중첩 필드, 기존값 보존 검사를 통과했다.
- 기존 Visual Feedback 검사도 통과했다(몬스터 13 / 소환수 7 프리팹, 반복 변형/취소, 물리 유지, 이펙트/셰이더).
- 그래픽 배치 에디터의 IMGUI 검사에서는 Unity TextCore가 CJK 동적 폰트 아틀라스를 만들 때 kDontSaveInEditor assertion을 기록했다.
  이 엔진 폰트 로그는 별도 집계하며, 다른 GUI 오류는 검사를 실패시킨다. 실제 에디터의 최종 글꼴/가독성 확인은 별도로 필요하다.
