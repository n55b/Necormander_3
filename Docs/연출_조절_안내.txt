기존 연출 조절 순서
1. FeedbackCatalog.asset에서 기존 효과의 ‘조절’을 누른다.
2. ‘조절 대상’에서 캐릭터/이펙트 프리팹 또는 재질을 고른다. 그 아래에 원본 설정이 펼쳐진다.
3. 수치·색·곡선을 바꾸면 실제 원본이 변경된다. 별도 복사본이나 전체 캐릭터 공통값으로 바꾸지 않아, 보스/일반 적/미니언별 차이를 유지한다. Undo도 가능하다.
4. 카메라·히트스톱처럼 씬에 직접 놓인 설정은 해당 씬을 선택하고 ‘이 씬 설정 불러오기’를 누른다. 현재 씬을 유지한 채 추가로 열리며 같은 Catalog 화면에서 수정·씬 저장을 할 수 있다.
5. 새로운 프리팹을 추가한 뒤에는 ‘기존 연출 연결 목록 새로고침’을 누른다. 기존 수치와 사용 체크는 유지한다.
에셋 수치 변경은 이미 생성된 개체에 복사되지 않는다. 다시 생성하거나 Play를 다시 시작해 확인한다. 사용 체크는 재생 중에도 반영된다.
기존 12종: 최종형 슬래시 / 스쿼시·스트레치 / 피격·회복 섬광 / 걷기 연기 / 대시 연기 / 대시·돌진 잔상 / 가림 실루엣 / 도트 디더링 / 화면·UI 페이드 / UI 흔들림 / 카메라 흔들림 / 히트스톱.
원본 그림 배율은 그대로다. 연기 ‘그림 재생 배속’ 1은 기존 속도이며, 종료 시간도 배속을 따른다.
디더링을 끄면 일반 알파 표시로 돌아간다. 페이드를 끄면 부드러운 보간만 생략하고 로딩 준비 전 암전·대기·입력 차단·완료 콜백을 유지한다.
카메라 흔들림과 히트스톱은 기존 호출과 신규 호출이 같은 공용 엔진을 사용하므로, 해당 기존 항목을 끄면 공용 엔진의 해당 효과도 꺼진다.

자주 바꾸는 값
- 사용: 체크를 끄면 해당 종류의 연출을 중단한다. 이미 재생 중인 효과도 정리하거나 원상복구한다.
- 연출 강도: 1이 기본. 먼저 0.5로 낮춰 보고, 완전히 빼려면 체크를 끈다.
- 지속 시간 / 시작 지연: 보이는 시간과 뒤늦게 나오는 시간을 초 단위로 정한다.
- 빛 조각 수 / 퍼지는 거리 / 선 굵기: 주변 도형만 바꾼다. 원본 도트 그림은 확대하지 않는다.
- 32 PPU 기준 선 굵기 0.03125는 월드 1픽셀이다.
- 움직임 곡선: 가로는 0~1 수명, 세로는 진행 비율이다.
- 최소 성장 단계: 이 단계 이상에서만 월드 효과를 낸다.
- 성장에 따른 강약 적용: 성장 단계의 강도·입자 수·거리 배율을 적용한다.
- 같은 효과 최소 간격: 같은 효과가 몰릴 때 일부를 생략하는 출력 제한이다.
- 추가 효과음 / 크기 / 음높이 변화: 기존 소리를 작은 볼륨으로 겹친다. 80번을 끄면 미세 변화를 끈다.
수치를 바꾸면 다음 생성부터 적용된다. 사용 체크는 현재 재생 중인 연출에도 적용된다.
Play 모드에서 조절한 ScriptableObject 값은 남을 수 있으므로 원래 값을 먼저 기록해 둔다.

발소리를 짧고 작게, 대시·회복·함정·소환/귀환 소리를 낮춤. 미니언은 등장과 귀환 때 그림만 실체화/소멸. 방 이동은 플레이어 본체가 위로 빠졌다 되돌아오는 연출로 교체. Hover 소리에 3픽셀 상승 동작, 시작 화면에도 소리 배치. 용사는 휘두르기와 실제 적중 소리 분리. 선택한 퍼펙트 가드/엘리트 두 공격음 편집·연결. 사망음은 OpenGameArt의 Erase / Escape로 교체하고 초반 폭발음 제거.
