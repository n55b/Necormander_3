가장 먼저 열 곳
Assets/Resources/FeedbackCatalog.asset
이 에셋 하나에서 이번 신규 연출을 전체 또는 개별로 켜고 끈다.
Inspector의 ‘효과 찾기’에 번호나 이름을 넣고 ‘조절’을 누르면 수치가 펼쳐진다.
번호는 Docs/이펙트_후보_2026-10-26.txt의 80개 후보와 동일하다.
가드 후보 09~16은 제외했다. 기존 우클릭 가드·게이지·UI는 그대로다.
상태이상 후보 33~38도 보류했다. 아래에 다음 작업 메모를 남겼다.

적용 범위와 예외
총 66개 설정을 준비했다. 현재 존재하는 동작 65개에 연결했다.
47번 관통 통과 섬광은 현재 실제 관통 투사체가 없으므로 호출 훅만 준비했다.
관통형 Projectile 파생 클래스에서 대상을 실제로 통과했을 때 FeedbackPierced(point)를 호출한다.
일반 투사체를 관통탄으로 바꾸지는 않았다.
기존 슬래시·스쿼시·디더링·연기 등은 기존 설정을 유지하며, 아래 별도 위치에서 조절한다.
전체 끄기는 이번에 추가한 연출을 끄는 설정이다.

자주 바꾸는 값
- 사용: 체크를 끄면 해당 신규 연출만 중단한다. 이미 재생 중인 월드 효과도 정리한다.
- 연출 강도: 1이 기본. 먼저 0.5로 낮춰 보고, 완전히 빼려면 체크를 끈다.
- 지속 시간 / 시작 지연: 보이는 시간과 뒤늦게 나오는 시간을 초 단위로 정한다.
- 빛 조각 수 / 퍼지는 거리 / 선 굵기: 주변 도형만 바꾼다. 원본 도트 그림은 확대하지 않는다.
- 32 PPU 기준 선 굵기 0.03125는 월드 1픽셀이다.
- 움직임 곡선: 가로는 0~1 수명, 세로는 진행 비율이다.
- 최소 성장 단계: 이 단계 이상에서만 월드 효과를 낸다.
- 성장에 따른 강약 적용: 성장 단계의 강도·입자 수·거리 배율을 적용한다.
- 같은 효과 최소 간격: 같은 효과가 몰릴 때 일부를 생략하는 출력 제한이다.
- 추가 효과음 / 크기 / 음높이 변화: 기존 소리를 작은 볼륨으로 겹친다. 80번을 끄면 미세 변화를 끈다.
수치를 바꾸면 다음 생성부터 적용된다. 사용 체크는 현재 재생 중인 연출에도 적용된다.
Play 모드에서 조절한 ScriptableObject 값은 남을 수 있으므로 원래 값을 먼저 기록해 둔다.

출력·정리 안전장치
기본 상한은 월드 효과 동시 72개, 프레임당 12개, 추가 효과음 프레임당 3개다.
같은 월드 효과 프리팹은 비활성 풀에 돌려 재사용한다. 씬에 속하므로 씬 종료 시 같이 정리된다.
환경 효과는 플레이어 근처에서만 나온다. HP·피해량·충돌체·캐릭터/맵 루트는 바꾸지 않는다.
시간 연출은 기존 HitStopManager, 카메라는 기존 CameraManager, 소리는 기존 SoundManager를 사용한다.
기존 UI 일시정지를 히트스톱 종료가 풀어버리지 않도록 복구 조건을 확인했다.
신규 그래픽 생성 AI는 사용하지 않았다. 기존 그림·소리와 Unity 기본 도형/셰이더만 사용했다.

검증과 플레이 확인
Unity 컴파일, 한글 인스펙터/Undo, 기존 스쿼시·디더링·슬래시 1배 유지 검사를 실행했다.
격리 Play Mode에서 66개 설정 호출, 수명 종료, 출력 상한, 전체 끄기, 풀 반환, 감속 원복, UI 일시정지 보존을 검사했다.
효과 도형을 실제 렌더링해 확인했고, 국소 굴절은 렌더 결과의 픽셀 변화도 검사했다. 전체 게임 전투를 수동으로 끝까지 플레이한 것은 아니다.
플레이에서는 기본 무기→강화 무기→최종 미니언 순으로 공격하고, 대시/소환/회복/상자/포탈/보스 집행·사망을 확인하면 된다.
과하면 Catalog에서 해당 번호만 끄거나 강도·입자 수를 먼저 낮춘다.
