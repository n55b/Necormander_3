# Necromander 툴 사용 가이드

## 인게임 레벨 제작실

처음 들어가면 **내 작업**이 열린다. 왼쪽 **방 만들기**에서 새 방을 시작하고, 오른쪽 **내 방**에서는 저장한 방의 이름이나 썸네일을 눌러 연다. 이름 일부를 입력하고 Enter 또는 **검색**을 누르면 목록이 좁혀진다. 프로젝트 DATA에 연결된 제작실에서는 아래 **게임 콘텐츠**(또는 작업대 밖 머리줄의 같은 탭, Ctrl+F 찾기)에서 플레이어·소환수·몬스터·아이템·장비·상태이상·화면·연출·사운드·대사·번역·아트 원본과 **모든 수치**를 연다. 아직 전용 화면이 없는 타일은 그 영역만 걸러 낸 모든 수치를 연다. 작업대와 허브의 **최근** 칩은 마지막으로 연 콘텐츠다. 프로젝트에 연결하지 않았거나 작업 공간 사본에서는 허브가 읽기 전용이다.

방을 열면 오른쪽 **지형 그리기**에서 자동 타일·칠하기·지우개·스포이드를, **배치와 선택**에서 적·소품·출구·시작점을 고른다. 지도 아래 첫 줄은 현재 도구의 사용법이나 마지막 작업 결과를 표시한다. **저장 필요**가 보이면 Ctrl+S로 저장하고 F6으로 시험할 수 있다.

Unity에서 **Tools > Sunyunie Panel > 레벨 제작실로 플레이 시작**을 누르면 Game 뷰에서 바로 제작할 수 있다. 작업하던 씬은 Play를 멈추면 다시 보인다. 이미 마을이나 던전을 플레이 중이라면 같은 자리에 있는 **현재 플레이에서 레벨 제작실로 이동**을 누른다. 상단 메뉴 **Tools > Level Workshop > Open in Play Mode**도 같은 동작을 한다.

방을 시험하려면 **내 작업 > 새 방 만들기 > 플레이**를 누른다. **편집으로 F6**을 누르면 방으로 돌아온다. 층·배치 시드·방 수·웨이브는 **게임 설정 > 던전**에서 바꾼다. **설정 저장**은 작업 공간에 값을 기록하고, **무대 플레이**는 현재 설정으로 시험 층을 연다. 플레이어가 있는 씬에서 **Sunyunie Panel > 화면·이동 > 플레이어 이동과 근접 공격**을 열면 **현재 플레이어 · 시험값**을 즉시 바꿀 수 있다. 이 값은 해당 플레이어 인스턴스에만 적용된다. **기본값 · DATA**는 읽기 전용이며 DATA `BALANCE/PLAYER` 값과 프리팹 값을 함께 보여 준다. 플레이어가 생성될 때 DATA 값이 프리팹 값을 덮어쓰므로, 기본값은 **제작실 > 게임 콘텐츠 > 플레이어**에서 편집한다. 같은 자리의 **제작실에서 플레이어 수치 편집** 버튼이 제작실을 연다.

**지도 화면**에서 1×는 원본 16픽셀 타일 한 칸이 화면에서도 16픽셀이 되는 배율이다. 휠은 포인터 아래를 기준으로, 하단의 **+ / −**는 화면 중앙을 기준으로 확대·축소한다. 가운데 마우스 버튼으로 지도를 끌고 **전체 보기**로 방을 한눈에 볼 수 있다. **원위치**는 바닥 중심의 1× 보기로 돌아간다.

**자동 타일**에서 재료를 고르고 지도에 드래그한다. **흙길·풀밭**은 바닥에, **벽·절벽·물가**는 통행을 막는 벽 레이어에 그려진다. 벽은 돌로 덮이고 절벽은 풀로 덮인다. 물가는 가장자리에 얕은 물과 흙이 드러난다. 세 재료 모두 아래쪽 바닥을 보존하므로 지우면 원래 바닥이 나타난다. 가장자리와 모서리는 주위 여덟 칸에 맞춰 바뀐다. 지우개·도장·실행 취소에도 같은 규칙이 적용된다. **칠하기**로 놓은 기존 그림은 그대로 유지되고 자동 타일이 같은 계열의 주변 그림을 이웃으로 인식한다. 재료 팔레트에서는 이름 일부로 타일·적·소품을 검색할 수 있다. 다섯 지형의 원본은 `ARTIST/WORLD/TILES/Field_Tilemap_16px.aseprite`이며, 시트를 수정하면 해당 지형의 연결 모양 47종도 다시 생성된다.

방을 저장하고 **던전 등록**을 누르면 일반 던전에서 원본 방과 같은 자리에 등장할 수 있다. 등록된 **절벽 물가**는 1층 배치 시드 916에서 확인할 수 있다. 실제로 연결된 출구는 폭 세 칸으로 열리며 문 안쪽 착지점까지 통로가 확보된다. 문 바로 옆에 남길 지형은 이 세 칸 바깥에 칠한다. **출구 → 방향 → 연결 미리보기**에서 현재 편집 중인 배치와 연결 결과를 나란히 본다. 왼쪽은 걷힐 칸과 보충할 바닥, 오른쪽은 통로·착지점과 거기서 상하좌우로 이어진 바닥을 표시한다. **방 전체**로 이동 범위를 확인하고 **표시 숨기기**로 지형 그림만 비교할 수 있다.

**선택**으로 그림을 클릭하면 선택된 오브젝트의 이름과 민트색 테두리가 보인다. 빈 곳을 끌면 영역에 걸친 그림을 함께 선택하고, Shift를 누른 채 클릭하면 개별 선택을 추가하거나 해제한다. 그림이 겹치면 Alt를 누른 채 같은 지점을 클릭해서 뒤에 있는 배치물까지 순서대로 선택한다. 선택한 그림을 끌어 옮기거나 **선택한 배치물 수치**를 눌러 좌표를 입력한다.

제작용 Windows 프로그램은 `Builds/LevelWorkshop/Windows/NecromanderWorkshop.exe`다. 팀원에게는 Windows 폴더 전체를 전달한다. 메인 메뉴 오른쪽 위 **레벨 제작실**을 누르면 같은 작업 화면이 열린다.

팀 검수용 ZIP은 `Builds/LevelWorkshop/NecromanderWorkshop-team-*.zip`에 있다. 같은 ZIP을 두 PC에 풀면 실행 파일과 [두 사람용 검수표](제작실_두_PC_검수.md)가 함께 들어 있다.

1. **내 작업 > 새 방 만들기**는 일반 방을 복제한다. 다른 틀을 쓰려면 **Legacy**에서 발자국 모양의 방 썸네일과 용도를 보고 복제한다. **Legacy > 기존 도구**는 팀의 MapDesign 씬, 원본 설정, 종전 편집기의 위치를 보여준다. Unity 플레이 모드에서는 이 화면에서 해당 에셋을 선택하거나 편집기 창을 열 수 있다.
2. 왼쪽 위 이름 칸에 방 이름을 입력한다. 오른쪽에서 **칠하기**를 선택하고 레이어 아래 재료 이름을 누르면 그림이 있는 재료 서랍이 열린다. 타일은 끌어서 칠하고, 적과 소품은 눌러서 배치한다. **선택**으로 오브젝트를 끌고 **출구**로 방향별 문 위치를 정한다. 가운데 버튼은 지도 이동, 휠은 커서 중심 확대다. 한 획 취소는 Ctrl+Z, 다시 실행은 Ctrl+Shift+Z다.
3. **시작점**으로 걸을 수 있는 바닥을 지정하고 **플레이**를 누른다. **입구부터 플레이**는 문 안쪽에서 시작한다. F6 또는 화면 위 **편집으로**를 누르면 방과 실행 취소 기록으로 돌아온다. **저장**은 내 작업 목록에 이 방을 기록하고, **공유본**은 팀에 전달할 JSON을 만든다. 같은 버전의 제작실에서 **공유 > 공유 폴더 열기**로 파일을 넣고 다시 들어와 **가져오기**를 누른다. 가져온 방은 새 ID로 저장된다.
4. **게임 설정**에서 던전·엘리트·튜토리얼·마을 중 시험할 무대를 고른다. 던전은 층, 시드, 목표 방 수와 일반 전투 웨이브를 조정할 수 있다. 최소 일반 방과 특수방 수는 층 설정을 따르므로 실제 방 수는 지도에 나온 결과를 확인한다. 지도 칸을 눌러 수정하고 **층에 연결**한다. **무대 플레이**를 누르면 미리 본 배치로 들어간다. 연결은 무대, 층, 시드, 격자 위치와 원본 방이 일치할 때 적용된다. 마을에서는 기존 마을을 시험 플레이할 수 있다.
5. 기존 방은 **내 작업 → 게임 방 편집 → 게임 원본 편집**에서 수정하고 저장한다. 새 방은 저장한 다음 **던전 등록**을 누른다. 두 경우 모두 다음 일반 던전 생성에서 프로젝트 데이터를 사용한다. 기존 프리팹 변형이 필요한 작업은 **Tools > Level Workshop > Legacy > Import room as new prefab variant**에서 가능하다. Windows 팀원에게 배포할 때는 **Build Windows creator**로 다시 빌드한다. 방 프리팹이나 그 안에 든 소품 프리팹을 고친 뒤 빌드가 '원본 방의 버전이 다릅니다'로 멈추면 **Tools > Level Workshop > Rebase project rooms**를 실행한다. 카탈로그를 다시 굽고 `DATA/WORLD/ROOMS` 문서를 새 원본 위에서 검증한 뒤 기준 버전을 옮긴다. 카탈로그와 바뀐 `room.json`을 함께 커밋한다.

**여러 소품이나 적을 함께 옮기기.** **선택**을 누른 뒤 빈 곳에서 사각형을 끌거나 Shift를 누른 채 오브젝트를 하나씩 클릭한다. 선택한 오브젝트 하나를 끌면 묶음 전체가 같은 거리만큼 이동한다. 묶음 이동과 삭제는 각각 Ctrl+Z 한 번으로 되돌린다.

**반복 무늬 찍기.** **도장**에서 레이어를 고르고 지도에서 복사할 사각형을 끈다. 최대 32×32칸까지 고를 수 있다. 지도에서 클릭한 칸이 도장의 왼쪽 아래가 된다. 빈칸은 건너뛰므로 기존 바닥 위에 띄엄띄엄 배치한 장식도 찍을 수 있다. **보관함**에서 이름을 입력하고 **새 도장 저장**을 누르면 다른 방에서도 같은 도장을 꺼내 쓸 수 있다. 다른 무늬를 복사할 때는 **다시 고르기**를 누른다.

**전투 정하기.** **전투 설정 > 웨이브 추가**로 최대 8개까지 만든다. 번호를 골라 **이전 군집 / 다음 군집**으로 적 구성을 바꾸고, **앞으로 / 뒤로**로 순서를 정한다. 고정 배치한 적을 먼저 처치하면 지정한 군집이 차례로 등장한다. 웨이브 수가 0이면 기존 방의 규칙을 사용한다. 방 클리어 보상은 방 종류가 정한다. 일반 방은 200골드와 아이템 1개, 엘리트·보스 방은 `RewardManager`의 드롭 개수만큼 아이템을 바닥에 떨어뜨린다.

**튜토리얼 순서 바꾸기.** **게임 설정 > 튜토리얼 > 방 순서 편집**에서 방을 고르고 **앞으로 이동 / 뒤로 이동**을 누른다. 시작 방과 마을 포탈이 있는 마지막 방은 고정된다. **순서 적용**은 문 방향과 방 겹침을 검사한 뒤 저장한다. 이미 연결해 둔 제작 방도 원본과 함께 이동한다. **무대 플레이**로 새 경로를 시험한다. **기본 순서 > 순서 적용**은 프로젝트 순서로 복원한다.

**마을에서 편집하기.** **게임 설정 > 마을 > 무대 플레이**로 들어가 왼쪽 위 **마을 편집**을 누른다. **이전 NPC / 다음 NPC**로 대상을 고르고 **지도에 놓기**를 누른 뒤 원하는 발 위치를 클릭한다. **표시 켜짐 / 꺼짐**으로 해당 NPC를 보이거나 숨길 수 있다. **원래 위치**는 선택한 NPC를 씬에 처음 배치된 자리로 돌린다. 인사말은 줄마다 대사 한 장이 된다. **대사 미리보기**로 읽어 보고, 시험 플레이 중에는 NPC에게 말을 걸어 인사말 뒤의 원래 상호작용까지 확인한다.

**마을 빛 저장하기.** **마을 편집 > 조명 조정**에서 태양·그림자, 블룸, 안개를 마을 위에서 조절한다. **마을 저장**을 누르면 NPC의 위치·표시·인사말과 현재 조명을 제작실 폴더의 `village.json`에 함께 기록한다. **F6**으로 돌아간 뒤 다시 **무대 플레이**를 누르면 마지막 저장본을 연다. 프로젝트의 기본 조명으로 돌아가려면 조명 창의 **장면 기본값 복원**을 누르고 **마을 저장**한다.

### 팀에 제작 묶음 전달하기

1. 보낼 방·층·마을에서 **저장**, **설정 저장**, **마을 저장**을 각각 누른다. **공유 → 제작 묶음**에서 팀이 알아볼 이름을 입력하고 **묶음 내보내기**를 누른다. 공유 폴더의 `.levelpack` 한 개에 현재 작업 공간의 모든 저장된 방, 층 연결, 튜토리얼 순서, 마을 NPC·대사·조명이 들어간다. 개인 도장과 자동 복구 초안은 로컬에 보관한다.
2. 받는 사람은 같은 버전의 제작실에서 **공유 폴더 열기**를 눌러 파일을 넣은 뒤 **제작 묶음 → 비교**를 누른다. **차이만 보기**를 누르면 선택이 필요한 항목만 남는다. 각 항목에서 내 저장본과 팀 공유본의 차이를 확인한다. 같은 방의 웨이브를 서로 다르게 바꿨다면 양쪽 군집 이름이 표시된다. 여러 종류의 차이가 있으면 **다음 차이**로 확인한다.
3. 내용이 다른 항목마다 **내 버전 사용** 또는 **팀 버전 사용**을 고른 뒤 **새 작업 공간으로 열기**를 누른다. 선택 단위는 방 하나, 층 설정 전체, 마을 설정 전체다. 새 작업 공간에는 공유본의 방과 선택한 층에서 추가로 참조하는 방이 들어간다. 방 ID가 유지되어 튜토리얼이나 던전에 다시 연결할 필요가 없다.
4. **공유 → 작업 공간**에서 기존 작업과 가져온 작업을 오갈 수 있다. 다음 실행에서도 마지막으로 열었던 작업 공간을 사용한다. 가져온 작업에서 수정해 다시 내보내면 받은 시점의 개정이 함께 전달된다. 양쪽이 같은 방을 고쳤을 때 이 기록으로 어느 쪽이 바뀌었는지 비교한다.

체크아웃을 연결한 제작판과 Unity 플레이 모드의 기본 작업 공간은 프로젝트 루트 `DATA`에 저장한다. Windows 제작판의 로컬 방, 개인 자동 복구 초안, 백업, 팀 공유 파일은 `%USERPROFILE%/AppData/LocalLow/Necromander/Level Workshop/LevelWorkshop` 아래에 있다. 공유 파일은 그 안의 `Shared`, 저장한 도장은 `Stamps`, 가져온 작업 공간은 `Workspaces`에 있다. Unity 플레이 모드의 개인 초안·공유 묶음은 해당 프로젝트의 `Application.persistentDataPath/LevelWorkshop`에 있다. 영역별 저장 위치는 [DATA 제작 안내](../../DATA/README.md)를 따른다. 이전 형식(v1)의 방도 열 수 있으며, 다시 저장하면 타일 색·변형과 웨이브를 담는 v2가 된다. 동료와 공유할 때는 같은 버전의 제작실을 사용한다.



프로젝트 안에 있는 에디터 툴과 게임 속 디버그 기능을 한곳에 모았습니다.
메뉴는 모두 유니티 상단 **Tools** 메뉴 아래에 있습니다.

> **읽는 법**
> - **기획자용**: 수치·모양·소리를 직접 만지는 툴입니다. 대부분 플레이 중에 바꿔도 바로 보입니다.
> - **셋업/배선**: 프리팹이나 에셋을 고치는 툴입니다. 누르기 전에 Git에 커밋해 두면 되돌리기 쉽습니다.
> - **검사**: 이름에 `Verify` / `Check` / `검증` / `검사` 가 붙은 메뉴는 **씬·에셋·세이브를 저장하지 않는** 회귀 검사입니다. 결과는 콘솔이나 `Logs/`, `Temp/` 폴더의 리포트로 나옵니다. 안심하고 눌러도 됩니다.

### 1-1. UI 스킨 · 연출 설정 — `Tools > UI 스킨`

| 메뉴 | 하는 일 |
|---|---|

**설정 파일에서 할 수 있는 것** (모든 칸에 마우스를 올리면 설명이 나옵니다)

- **④ 공통**: 연출 전체 켜기/끄기, 일시정지 중에도 재생할지, '툭 튀는 모양 곡선'.
- **⑤ 창 열림**: 큰 창 / 작은 창(툴팁) 각각 시작 크기, 걸리는 시간, 시작 투명도, 시작 위치, 곡선, 지연.
- **⑥ 체력 · 가드 게이지**: 피해 잔상(색·머무는 시간·줄어드는 시간·곡선), 맞았을 때 번쩍임·툭 튀기, 회복·보호막 번쩍임, 위험 경고(시작 비율·깜빡임 주기·색·세기).
- **⑦ 스킬 아이콘**: 쿨타임 중 테두리 색, 준비 완료 순간의 번쩍임·튀어오르기.
- **⑧ 마우스 반응**: 아이템 칸·버튼에 마우스를 올렸을 때 / 눌렀을 때 크기.

설정 화면 위쪽 버튼: **모양을 UI_Panel 기본값으로**, **연출을 기본값으로**, **인게임 UI 프리팹에 스킨 다시 붙이기**.

> 💡 플레이하면서 값을 바꾸면 즉시 보이고, 값은 그대로 저장됩니다.
> 💡 특정 창만 열림 연출을 다르게 하려면 그 창의 **창 열림 연출** 컴포넌트에서 `연출 종류` 를 `직접 설정` 으로 바꾸세요.

**관련 컴포넌트** (`Add Component > UI 스킨`)

| 컴포넌트 | 설명 |
|---|---|
| 스킨 이미지 (UI_Panel) | 이 Image 를 스킨 설정의 한 '역할'로 칠합니다. `원래 색 유지` 를 켜면 그림만 바꾸고 색은 코드가 정한 대로 둡니다. |
| 창 열림 연출 | 켜질 때 크기·투명도·위치를 움직여 등장시킵니다. |
| 마우스 반응 | 마우스 올림/누름 크기 변화. |
| 게이지 연출 (체력 · 가드) | 피해 잔상, 번쩍임, 위험 경고. 바의 값을 읽기만 합니다. |
| 스킬 아이콘 연출 | 쿨타임 중 테두리 어둡게, 준비 완료 번쩍임. |
| 항상 맨 앞에 그리기 | 나중에 생기는 형제(미니맵 방 아이콘 등)보다 항상 위에 그립니다. |

### 1-2. 사운드 테스트 툴 — `Tools > 사운드 > 사운드 테스트 툴`

소리를 넣고 **바로 들어보는** 창입니다. 위쪽 탭이 두 개입니다.

- **[오브젝트 소리]**: 몬스터 · 소환수 · 캐릭터 · 사물의 소리 (아래 설명)
- **[UI 소리]**: 창 열림/닫힘, 버튼 · 아이템 칸, 상점 구매 성공/실패 소리 (→ 1-2-1)

**오브젝트 소리 — 기본 순서**

1. Project 창에서 프리팹(예: 몬스터 프리팹)을 클릭합니다. (`선택 따라가기` 가 켜져 있으면 자동으로 대상이 됩니다)
2. 사운드 세트가 없으면 **이 프리팹에 사운드 세트 붙이기** 를 누릅니다.
   - 씬 오브젝트를 골랐다면 **프리팹 원본에 붙이기(권장)** 를 누르면 같은 프리팹을 쓰는 모든 오브젝트에 들어갑니다.
3. **+ 소리 추가 ▼** 에서 `공격 / 피격 / 사망 / 회복 / 등장 / 스킬 / 발소리 / 직접 호출` 중 하나를 고릅니다.
4. 오디오 파일을 **"여기에 오디오 파일을 끌어다 놓으세요"** 칸에 끌어다 놓습니다. 여러 개 넣으면 매번 무작위로 하나가 나옵니다(같은 파일 연속 방지).
5. **▶ 테스트** 로 들어봅니다. 볼륨·음높이·무작위 선택이 실제 게임처럼 적용됩니다. 파일 옆 ▶ 는 그 파일만 들려줍니다.

**화면 구성**

| 위치 | 기능 |
|---|---|
| 위 막대 | 대상 고르기, 선택 따라가기, **미리듣기 볼륨**(툴 전용, 게임 값 안 바뀜), **단순 미리듣기**(▶ 를 눌러도 소리가 안 나면 켜 보세요), **■ 정지** |
| 왼쪽 | 소리 목록. 이름, **언제 재생**, 소리 파일들, 볼륨, 음높이 범위(최소~최대 무작위), 최소 재생 간격, 지연 |
| 오른쪽 | **오디오 파일 찾기**: 이름으로 검색 → ▶ 로 듣기 → 왼쪽 소리의 체크칸을 켜고 **[+]** 로 추가. 목록에서 왼쪽으로 끌어다 놓아도 됩니다. 더블클릭하면 Project 창에서 위치를 보여줍니다. |
| 아래 | **재생 기록**: 플레이 중 실제로 난 소리(시각 · 누가 · 어떤 소리 · 어떤 파일)와 **열리고 닫힌 창 이름**. "왜 소리가 안 나지?"를 확인할 때 씁니다. |

**"언제 재생" 종류**

| 선택지 | 연결 방식 |
|---|---|
| 나타날 때 | 오브젝트가 켜질 때 (소환, 스폰) |
| 공격이 맞는 순간 | 애니메이션 이벤트 `OnHitEvent` (몬스터 공격 클립에 이미 들어 있는 이벤트) |
| 공격 동작 끝 | 애니메이션 이벤트 `OnAttackEndEvent` |
| 맞았을 때 / 회복했을 때 / 죽을 때 | 같은 오브젝트(또는 자식)의 체력(CharacterHealth)에 자동 연결 |
| 직접 호출 | 애니메이션 이벤트 함수 이름 `PlaySound`, 문자열 인자에 **소리 이름** (예: `발소리`). 코드에서는 `GetComponent<EntitySoundSet>().PlaySound("발소리")` |

> 💡 Animator 가 자식 오브젝트에 있어도 괜찮습니다. 실행 중에 중계 컴포넌트가 자동으로 붙어 이벤트를 받아옵니다.
> 💡 **최소 재생 간격**: 몬스터 여러 마리가 한꺼번에 맞을 때 같은 소리가 겹쳐 터지는 것을 막습니다.
> 💡 플레이 중이고 대상이 씬 오브젝트면 **게임▶** 버튼이 생깁니다. 옵션의 효과음 볼륨·믹서까지 반영해서 게임 안에서 재생합니다.
> 💡 사운드 세트 인스펙터의 **사운드 테스트 툴에서 열기** 버튼으로도 열 수 있습니다.

플레이어의 공격·구르기·가드·피격 소리는 기존처럼 `PlayerAttackSoundData`(Create > Audio > PlayerAttackSoundData) 에서 관리합니다.

#### 1-2-1. UI 소리 — 사운드 테스트 툴 [UI 소리] 탭

**버튼 소리 붙이기** — `Tools > 사운드 > UI 버튼에 소리 붙이기` (또는 [UI 소리] 탭 위쪽 버튼)

- 인게임 UI 프리팹의 버튼에 **UI 버튼 소리** 컴포넌트(`Add Component > 사운드 > UI 버튼 소리`)를 붙입니다. 이미 붙어 있는 버튼은 건드리지 않으니 여러 번 눌러도 안전합니다.
- 아이템 주머니 칸은 `아이템 칸`, 정렬 버튼은 `탭 버튼`, 나머지는 `일반 버튼` 으로 자동 분류됩니다.
- 상점 구매 버튼은 성공/실패 소리가 따로 나므로 `클릭 소리` 가 꺼진 채로 붙습니다.
- 컴포넌트에서 종류, 마우스 올림 / 클릭 소리 켜기, **이 버튼 전용 소리**(비우면 공용 소리)를 고칠 수 있습니다. 눌릴 수 없는(비활성) 버튼은 소리를 내지 않습니다.
- 씬에만 있는 UI(옵션 창 등)의 버튼은 직접 컴포넌트를 붙이면 됩니다.

> ⚠️ 상점에서 골드가 모자라도 구매 버튼은 이제 **눌립니다**(글자는 "골드 부족" 그대로). 눌렀을 때 실패 연출과 **구매 실패** 소리가 나도록 하기 위해서입니다.
> 💡 연출(피드백)의 `Purchase` 에 이미 소리가 들어 있다면 **구매 성공** 칸은 비워 두어 겹치지 않게 하세요.

## 월드 앞뒤 정렬

- 캐릭터의 발, 나무 줄기와 바리케이드처럼 땅에 닿는 사물 위치에 기준점을 둔다. `YSortableObject`의 기준점을 비우면 오브젝트 피벗을 사용한다. 다른 기준이 필요하면 자식 `SortPoint`를 연결하거나 로컬 오프셋을 조정한다. 선택한 오브젝트에서는 Scene View에 청록색 기준점이 나타난다.
- 몸·손·무기처럼 한 물체의 파츠는 `SortingGroup` 아래에 두고 대표 스프라이트의 `YSortableObject`에 그룹을 연결한다. 파츠의 `Order in Layer`는 묶음 안에서만 쓰인다. 접점이 같은 두 물체는 `Tie Priority`의 큰 값이 앞에 그려진다.
- 긴 울타리처럼 위치에 따라 가리는 면이 달라지는 리소스는 구간별 스프라이트와 접점으로 만든다. 각 구간은 독립된 월드 정렬 오브젝트로 배치한다.
- 바닥·바위 지형 타일은 `Ground`, 그림자는 `Shadow`, 피해 예고 채움은 `Ground Effects`에 배치한다. 밟는 지형 위로 솟아 캐릭터를 가려야 하는 그림은 접점을 가진 월드 프리팹으로 배치한다.
- 마을에서 바리케이드 뒤와 앞으로 이동해 발만 가려지는지 확인한다. 몸통까지 가리는 큰 사물은 플레이어 주변의 불투명한 부분에 둥근 안개가 퍼지며 실제 캐릭터와 손이 드러난다.


## 전투 카메라와 시간

마을 또는 전투 씬의 Play Mode에서 **Tools > Sunyunie Panel > 연출**을 연다. 타격별 프리셋의 반동 거리는 640×360 기준 픽셀, 반동과 히트스톱 시간은 밀리초다. 방향 보정은 공격 벡터에 더하는 각도이고, 감쇠 지수가 높을수록 빨리 잦아든다. 미리보기 버튼은 피해를 발생시키지 않는다. 최근 요청에서 병합·교체·적용 결과를 확인한다.

같은 타격이 여러 대상을 맞히면 개별 대상의 효과는 각각 재생하고 카메라는 한 번 반응한다. 같은 프레임의 여러 요청은 우선순위, 반동 크기 순서로 선택한다. 다음 다단히트는 별도 요청이다. 스킬 에셋의 흔들림 배율과 히트스톱 시간은 실제 적중 시 반영한다. 일시정지는 진행 중인 시간 효과를 정리한다. 보스 처치는 짧은 정지가 끝나면 슬로모션으로 이어진다.

## 플레이 중 조명 조절

마을이나 던전에서 **F8**을 누르면 게임 화면 우측 상단에 조명 디버그 패널이 열린다. Unity에서는 Play Mode의 **Tools > Sunyunie Panel > 분위기**에서도 열 수 있다. 패널을 접으면 조정한 화면으로 계속 플레이할 수 있다.

| 탭 | 조절 항목 |
| --- | --- |
| 태양 | 방위각, 고도, 빛 강도, RGB 색, 그림자 강도, 하이라이트, 구름 그림자 |
| 분위기 | 픽셀 블룸의 강도·밝기 기준·반경, 지면 안개, 빛줄기, 안개 바람, 환경 입자량, 나무 바람, 공간 깊이 |
| 외곽 안개 | 화면 테두리의 강도, 논리 픽셀 단위 폭, 변화 속도 |

환경 입자량을 0으로 내리면 원경의 반짝임과 근경의 포자·잎·먼지·불씨가 함께 사라진다. 안개와 빛줄기는 같은 화면에서 따로 조절한다. 방 종류별 기본 밀도와 색은 Sunyunie Panel의 분위기 프로필에서 조정한다. `airborne`은 방의 입자량, `airPalette`의 X와 Y는 은청색 바탕에 섞는 민트색과 장밋빛의 비율이다.

**공간 깊이**는 방 프로필의 `depth`에 대한 비율이다. 허수아비 앞을 가로질러 걸으면 발밑의 낮은 안개와 머리 위로 지나가는 입자의 속도 차이를 비교할 수 있다. 0으로 내리면 원경과 지면 음영이 사라지고 공간 시차도 꺼진다.

**태양 → 구름 그림자**로 바닥에 지는 구름 그늘의 농도를 조절한다. **분위기 → 안개 바람 배율**을 0으로 내리면 구름도 그 자리에서 멈춘다. 방마다 기본 농도는 분위기 프로필의 `cloudShadow`를 사용한다. 구름 윤곽 원본은 `ARTIST/EFFECT/CloudCover.aseprite`다. `Cumulus banks`에서 큰 구름을, `Trailing veils`에서 얇은 꼬리를 그린다. 흰색이 짙은 구름이고 검은색이 맑은 하늘이다. 256×256 캔버스의 맞은편 경계가 서로 이어지게 그리면 이동 중에도 자연스럽게 반복된다.

태양 방향 0°는 화면 오른쪽, 90°는 위쪽이다. 낮은 고도에서는 그림자와 빛줄기가 길어지고, 태양이 머리 위로 오면 빛이 바닥에 넓게 맺힌다. RGB와 빛 강도는 현재 방의 기본광에 곱해진다. 방 프로필의 `shaftColor`는 직사광의 색, `shadeColor`는 그늘의 간접광 색이다.

블룸 밝기 기준을 낮추면 더 많은 월드 스프라이트가 주변 픽셀을 밝힌다. 반경은 번지는 거리, 강도는 번진 빛의 밝기를 조절한다. 횃불은 중심과 주변 안개를 함께 밝히고 소환사의 손에는 자세를 따라가는 민트색 빛이 있다. 화면 글자와 HUD는 이 조명 뒤에 합성한다.

**장면 기본값 복원**을 누르면 현재 방의 원래 조명으로 돌아간다. 슬라이더 값은 현재 플레이 세션 동안 유지되며 게임을 다시 실행하면 원래 설정으로 시작한다.

## 문구 연출과 미리보기

제작실의 **내 작업 → UI·보상 번역** 또는 **대사 편집**에서 문장을 입력한 뒤 꾸밀 단어를 드래그한다. **타이핑**, **물결**, **민트색**을 누르면 선택한 범위가 바뀐다. 선택 범위가 비어 있으면 문장 전체에 적용한다. **다시 재생**으로 효과를 처음부터 확인한 뒤 **프로젝트에 저장**을 누른다. 편집 칸에는 태그가 담긴 원문이 보이고 아래에는 게임에서 그릴 문구가 보인다.

| 원하는 표현 | 원문 예시 |
| --- | --- |
| 한 글자씩, 기본 속도의 1.5배 | `<type=1.5>문이 열립니다.</type>` |
| 한 단어를 지정한 색으로 | `<color=#AFDFC9>서리</color> 정령` |
| 한 단어만 반복해서 물결치게 | `<wave>서리</wave> 정령` |
| 민트색에서 금빛으로 서서히 반복 | `<fx=Enchantment><color=#AFDFC9>서리</color></fx>` |

게임의 공용 비트맵 텍스트 컴포넌트인 `PixelText`가 새 문구를 받을 때 태그를 읽는다. 숫자와 가격은 즉시 읽을 수 있고, 일반 대사는 기존 대화 속도·구두점 휴지·넘기기 입력을 사용한다. 모션을 끄면 타이핑 문장은 즉시 표시된다. 다른 문구에도 같은 효과를 쓰려면 **Tools → Sunyunie Panel → 글자 모션**에서 프리셋 ID와 속도·반복·이동 픽셀 수를 조정한다. 스킬 용어의 기본색과 반복 프리셋은 `KeywordDictionary`의 단어별 설정을 따른다.

공용 버튼과 패널 원화는 `ARTIST/UI/Vector/Chrome`에 있다. 제작실·조명 패널 등 코드로 띄우는 창의 기본 표면, 버튼, 포커스, 선택 상태는 `Assets/Resources/UI/Chrome.asset`에서 연결한다.
