# 두 사람이 이어서 방 만들기

두 PC에 같은 ZIP을 풀고 각자 `Windows/NecromanderWorkshop.exe`를 실행한다. 첫 화면에서 **레벨 제작실**을 연다. 기존 작업이 있는 사람은 새 방에 이번 검수용 이름을 붙인다.

### 첫 번째 제작자

1. 제작실 첫 화면에서 시간을 잰다. 기존 일반 전투 방 하나를 복제해 이름을 붙이고, 문 하나를 옮기고, 적 하나를 배치한다. 도움 없이 5분 안에 그 방의 시험 플레이를 시작하는 것이 목표다.
2. 편집으로 돌아와 수정한 방을 저장한다. 제작 묶음(`.levelpack`)을 만들어 동료에게 전달한다.

### 두 번째 제작자

1. 다른 PC에서 받은 묶음을 독립 작업 공간으로 연다. 첫 번째 제작자의 설명 없이 방을 찾아 시험 플레이하고, 이동한 문과 배치된 적의 위치를 기록한다. 두 사람이 적어 둔 위치를 대조한다.
2. 방의 클리어 보상을 바꾸고 저장한다. 제작실을 완전히 종료했다가 같은 작업 공간을 열어 보상이 복원됐는지 확인한다.
3. 두 번째 묶음을 돌려보낸다. 첫 번째 제작자는 이를 새 작업 공간에서 열어 동료의 보상을 확인하고, 자신의 원래 작업 공간으로 돌아가 이전 보상도 확인한다.

### 결과 기록

| 항목 | 기록 |
| --- | --- |
| 날짜와 각 PC의 제작실 ZIP 이름 | |
| 첫 제작자가 시험 플레이에 진입하기까지 걸린 시간 | |
| 받는 사람이 방을 찾아 시험 플레이하기까지 걸린 시간 | |
| 옮긴 문과 배치한 적의 위치가 서로 일치했는지 | |
| 재실행 후 보상, 재전달 후 두 작업 공간의 보상 | |
| 도움이 필요했던 화면과 찾고 있었던 기능 | |

막힌 지점에서는 경과 시간과 당시 화면을 먼저 남긴다. 그 뒤 제작 가이드를 보고 마친 동작은 결과에 함께 표시한다.
