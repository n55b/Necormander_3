# 번역 사용법

공식 패키지(Unity Localization)를 쓴다. 원칙은 하나다.

> **한국어는 원래 고치던 곳에서 그대로 고친다. 다른 언어는 번역 표(`Game Text Table`)에만 넣는다.**

번역 표의 한국어(ko) 칸은 자동으로 채워지는 사본이다. 거기서 한국어를 고쳐도 다음 갱신 때 원문으로 되돌아가니 표에서는 고치지 않는다.

---

## 기획자: 글 고치기·추가하기

| 무엇 | 한국어 고치는 곳 | 번역 키 |
|---|---|---|
| 아이템·장비·소환수·스킬·증강·상태이상 이름/설명 | 기존 툴(Tools/기획) 또는 인스펙터 | 자동 |
| 프리팹 안 컴포넌트 글(예: 스킬 설명창 툴팁) | 인스펙터 글상자 | 글상자 아래 **번역 키** 칸에 직접 입력 |
| 화면에 고정된 글(코드가 안 바꾸는 TMP 글자) | TMP 글자 그대로 | 그 오브젝트에 `LocTMP` 붙이고 key 입력 |
| 대사 | `Assets/Data/Dialogue/*.csv` 의 `text_ko` 칸 | 없음(대사는 CSV 자체가 번역 파일) |
| 시작·옵션 메뉴 버튼 글 | `UI Text Table` (Localization Tables 창) | 기존 그대로 |

- 키 이름 예: `ui.pouch.heading`, `SkillExplainUI.crit_chance`. 같은 키는 같은 번역을 쓴다.
- 키가 비어 있으면 게임은 한국어를 그대로 보여준다(깨지지 않는다).

## 번역 넣기 (영어 등)

1. `Tools/번역/번역 표 갱신` — 새로 생긴 한국어를 표에 모은다. (에디터를 켤 때도 한 번 자동으로 돈다. 메뉴로 돌리면 안 쓰는 키 정리까지 한다.)
2. Project 창에서 `Assets/Settings/Localization/Game Text Table` 선택 → 인스펙터 오른쪽 위 **⋮** → **Export › CSV...**
3. 번역가는 CSV의 **en 열만** 채운다. (Key/Id 열과 ko 열은 건드리지 않는다. 엑셀이면 "CSV UTF-8"로 저장.)
4. 같은 메뉴에서 **Import › CSV(Merge)...** 로 넣는다. (그냥 `CSV...`는 CSV에 없는 키를 지우니 쓰지 않는다.)
5. 확인: `Window › Asset Management › Localization Tables` 에서 보거나, 게임 옵션에서 언어를 English로 바꿔 본다.

번역할 때 지켜야 할 것: `<color=...>`, `<sprite ...>` 같은 태그와 `{0}`, `{값}` 같은 칸은 그대로 남긴다.

대사 번역은 CSV에 `text_en` 칸을 새로 만들어 채우면 된다. 빈 칸은 한국어로 나온다.

## 프로그래머: 코드에서 글 띄우기

```csharp
label.text = Loc.T("PouchUI.empty", "비어 있음");          // 키와 한국어 둘 다 글자 그대로 적는다
label.text = Loc.F("RewardProcessor.evolve", "진화: {0}", name);
public LocText itemName;  // SO 글 필드는 string 대신 LocText (그대로 string 처럼 쓰면 번역된 글이 나온다)
```

- 저장·비교·딕셔너리 키처럼 **언어가 바뀌면 안 되는 곳은 `.ko`** 를 쓴다 (`item.itemName.ko`).
- `static readonly`·`const` 초기값에서 `Loc.T`를 부르지 않는다(언어가 정해지기 전에 굳어 버린다).
- `Loc.F` 의 한국어에 중괄호를 글자로 쓰려면 `{{ }}` 로 두 번 쓴다.
- 디버그 로그·에디터 전용 글은 번역하지 않는다.

## 언어 하나 더 추가할 때

1. `Edit › Project Settings › Localization` 에서 Locale 추가(Locale Generator).
2. 새 Locale 에셋에 Metadata **Fallback Locale → Korean** 을 넣는다(번역 빠진 글이 한국어로 나오게).
3. 일본어·중국어는 지금 폰트(ThinMulmaru)에 글자가 없다. TMP Settings의 Fallback Font에 Noto Sans JP/SC 같은 폰트를 하나 추가한다.
4. 옵션의 언어 목록은 자동으로 늘어난다.

## 알아 둘 것

- 첫 실행은 한국어. 플레이어가 옵션에서 고른 언어는 다음 실행에도 유지된다.
- 게임 중 언어를 바꾸면 고정 글자는 바로 바뀌고, 이미 열린 창의 글은 다시 열 때 바뀐다.
