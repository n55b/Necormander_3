# Necromander 개발 중간보고

외부고문 인계 · 2026년 11월 25일 · Unity 6000.0.59f2

**현재 상태**　게임과 인게임 제작실을 함께 시연할 수 있습니다. 이번 작업의 목적은 화면과 조작에 일관된 기준을 세우고, 기획자와 아티스트가 직접 콘텐츠를 수정해 게임에서 확인할 수 있게 하는 것이었습니다. 아래 변경은 로컬 작업본에 있으며 팀 저장소 반영과 최종 품질 승인이 남았습니다.

## 반영한 작업과 이어갈 기준

- **화면·UI**　640×360을 공통 설계 해상도로 두고 UI 원본 1픽셀의 크기를 통일했습니다. 실제 출력은 게임 창 해상도를 따르며 이동·애니메이션에는 소수점을 허용합니다. 한·영 비트맵 글꼴, 단색 둥근 패널, 호버·선택 상태를 정리하고 인벤토리·정보창·미니맵·게이지·바닥 이름표를 손봤습니다. 글자별 색상·타이핑·반복 모션과 피해 숫자 연출도 공용화했습니다.
- **월드·아트**　발의 지면 접점을 기준으로 캐릭터·사물의 앞뒤와 그림자를 정렬했습니다. 절벽 그림자, 수목의 흔들림과 가림 안개, 구름 그림자·블룸·비네트·환경 입자를 개선했습니다. 그림은 `ARTIST`의 Aseprite·UI 벡터 원본에서 관리하고, GPU 파티클은 공통 팔레트를 사용합니다. 새 떼의 대기·도주 동작은 Aseprite 태그로 나눴습니다. F8에서 조명·그림자·안개를 현장에서 비교할 수 있습니다.
- **전투·이동**　평타의 전진 거리와 발동 순서, 공격 중 이동·근접 조준 보정, 양손 복귀와 펫 따라잡기를 조정했습니다. 적 등장·피격·넉백, 공격 예고선과 투사체, 콤보 줌·히트스톱·마지막 처치에 피드백을 더했습니다. 일반 문 이동과 다음 층의 픽셀 분해·흡입 연출을 분리했습니다.
- **제작·협업**　제작실 첫 화면에서 새 방, 저장한 방, 게임 콘텐츠를 나눴습니다. 방에서는 자동 타일·출입구·통행 범위를 미리 보고 F6으로 시험합니다. Unity 플레이 모드에서 Ctrl+S로 지형·보상·밸런스·대사·번역을 `DATA`에 저장합니다. 같은 방의 지형과 보상도 다른 파일입니다. 기존 방과 팀 도구는 제작실의 Legacy 탭에서 찾을 수 있습니다.

- **유지보수**　이동·공격·피해·던전 생성·저장 로직의 담당 코드를 나눴습니다. 공통 조절값은 Sunyunie Panel에서 찾고, 증상별 담당 파일과 검사법은 작업·검증표에서 찾습니다. 퇴역 코드와 과거 프롬프트는 실행·기본 검색 경로 밖의 `Legacy`에 보관합니다.

## 검증한 범위

- **편집과 협업**　제작실의 저장·검색·재열기·시험 복귀와 7개 창 크기를 검사했습니다. 두 체크아웃에서 같은 방의 지형과 보상을 별도로 커밋·푸시한 뒤 병합해, 에디터와 Windows 게임 양쪽에서 두 변경이 살아 있는 것을 확인했습니다.
- **성능과 시연본**　이전 성능 검수에서 RTX 4060 Ti·1280×720 조건으로 층마다 적 64마리를 동시 처치하고 드롭·전환을 20층까지 반복했습니다. 자연 GC 측정 102,413프레임 중 16.7ms 초과는 0회였습니다. 11월 25일 시연 ZIP에서는 압축 해제 후 게임 창 실행과 DATA 669개 일치를 확인했습니다.

## 팀에 권하는 다음 순서

1. **개발 · 작업본 보존과 빌드 재현**　보고서 작성 전 `main`의 기준 커밋은 `4c7a4203`이며 스테이징은 0건입니다. 수정 1,017개·삭제 표시 99개·미추적 2,100개에는 기존 팀 변경도 포함될 수 있습니다. 담당자와 아트 원본·출력·메타의 짝을 확인해 커밋하세요. 방 카탈로그를 재생성하면 일부 방 버전이 달라집니다. 시연본은 저장된 카탈로그로 만들었으므로, 깨끗한 체크아웃에서 25개 방과 새 빌드의 호환을 먼저 재현해 주세요.
2. **기획·아트 · 실제 제작 한 사이클**　팀원 한 분이 설명 없이 방 만들기 → 절벽·물가 칠하기 → 보상 설정 → 던전 등록 → 플레이까지 진행해 보세요. 멈춘 지점을 다음 UX 개선 대상으로 삼고, 한·영 글자 잘림과 조명 속 공격 예고선 가독성도 함께 확인해 주세요.
3. **QA · 배포 기준 확정**　최신 시연본에서 새 게임부터 층 이동까지 수동 점검하고 20층 성능 검사를 다시 실행해 주세요. 내장 GPU 실측은 보류 중입니다. 해상도와 기기별로 타격감·이펙트 밀도·최악 프레임을 함께 보고 기본값을 결정하는 것을 권합니다.

**시연**　Windows ZIP을 풀고 `NecromanderWorkshop.exe` 실행 → 메인 메뉴의 레벨 제작실. Unity에서는 Tools → Level Workshop → Open in Play Mode.
